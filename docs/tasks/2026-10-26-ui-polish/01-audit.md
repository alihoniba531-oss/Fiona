## 问题清单

### P1：看得见的错误或明显妨碍使用

1. **AI 回复里的 Markdown 原样显示。**
   - 现象：`ChatBubble.tsx` 用 `whitespace-pre-wrap` 输出纯文本，列表的 `- `、`1. `、`**`、`#` 都直接露出来。
   - 规模：本地库 294 条 assistant 消息中，34 条含 `**`，21 条含编号列表，12 条含 `- ` 列表，3 条含标题。用 Claude 以后会更多。
   - 改法：自写一个只支持安全子集的渲染器，不新增依赖：
     - 段落、无序 / 有序列表（悬挂缩进）；
     - 标题：只放大字号、用墨色，不加粗；
     - 引用：左侧细竖线，像批注；
     - 行内代码；
     - `**强调**`：只换成墨色、去掉星号，不加粗。
   - 约束：不渲染 HTML、不生成链接；朗读文本同样去掉标记。

2. **设置页两个区块共用同一个 React key。**
   - 现象：`app/settings/page.tsx` 第 215 和 217 行的 `ChatModelSection` 与 `LocalWatchSection` 都写了 `key={username}`。控制台报「two children with the same key」（就是 dev 角标上的 3 Issues）。截图里「聊天模型」出现了两次，有一次「本机监控」不见了。
   - 改法：给两者分别加前缀，例如 `chat-model:${username}` 和 `local-watch:${username}`。

3. **手机输入区太高。**
   - 现象：输入区加底栏约占屏幕高度的 36%，消息区只剩一半出头。输入区有四层：
     - 输入框；
     - 「上传参考图 | 生成图片」；
     - 图标加发送；
     - 两行模型说明「聊天：Claude（Anthropic）· claude-haiku-5-5（不扣草莓）」「改用平台」。
   - 改法：
     - 工具和发送合成一行；
     - 模型说明压成一行短标签，点它去设置更换；
     - 空闲时输入区（不含底栏）在手机上不超过约 140px。

4. **两个一模一样的麦克风图标。**
   - 现象：「语音转文字」和「按住说话」都用 `Mic`。手机上「按住说话」的文字被隐藏，于是并排出现两个相同的图标。
   - 改法：见下面「待拍板」第 1 条。

5. **三个和图片有关的入口，意思混在一起。**
   - 「上传参考图」的作用是改图；
   - 「生成图片」是文生图；
   - 右侧没有文字的图片图标是「发图给 Chloe 看」。
   - 改法：见下面「待拍板」第 2 条。

### P2：一致性与信息密度

6. **抽屉里标题重复。** 抽屉页眉写着「设置」，旁边是「设置 | 账户」页签，页面里又有一个大号「设置」，分身、世界也一样。手机上会浪费约 120px 高度。改法：嵌入（`embed=1`）时隐藏页面自己的大标题和副标题，只留抽屉页眉。
7. **手机抽屉没盖满。** 右边缘和左下角露出底下页面的一条缝，还被透镜扭曲（分身抽屉右上角能看到错位的字）。
8. ~~桌面侧栏底部只写「200」，没有说明。~~ **复核后撤回**：`Sidebar.tsx` 第 136–137 行在数字下面有「草莓」二字，截图里是被开发模式的 Next 角标挡住了，正式版可见。
9. **输入区直接显示模型 ID。** `claude-haiku-5-5` 是系统写法，应该改成 `Claude Haiku 5.5` 这样的展示名。设置页里的型号按钮也一样。
10. **时间显示和 Chloe 说的不一致。** 界面按设备时区显示，Chloe 按北京时间说话。设备不在北京时间时，两边报的时间对不上，Chloe 在对话里也说过自己前面报的时间不对。见「待拍板」第 3 条。

### P3：次要

11. 独立打开 `/studio` 时，侧栏比其他页面低约 58px。平时它在抽屉里打开，影响小。
12. 世界页：
    - 「今日热点」和「生活」两栏内容完全相同，是分类兜底的问题，属于后端数据；
    - 抽屉里的星图被两侧列表挡住大半，只剩装饰作用。
13. 匹配页空态：右侧整片空白，只有左栏一行小字。应该说明匹配是什么，并给一个去开公开名片的入口。

## 待拍板

1. **两个麦克风合并还是区分？**
   - A（推荐）：保留一个麦克风按钮，轻点是转文字，按住是直接说话发送，用按钮提示和首次引导说明。
   - B：保留两个按钮，但「按住说话」改用声波图标，手机上也保留短字「按住说」。
2. **图片入口怎么收？**
   - A（推荐）：合成一个「图片」按钮，点开三项：发图给 Chloe 看 / 生成图片 / 改一张图。
   - B：维持现状，只给右侧图标补上文字「看图」。
3. **时间按哪个时区显示？**
   - A：界面统一用北京时间，和 Chloe 一致。
   - B：仍按设备时区显示，并把设备时区告诉 Chloe，让它按你所在的时间说话。
