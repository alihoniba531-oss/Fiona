# 场景类型清单

判定时先看这场戏完成了什么变化，再看人物数量、空间是否连续和画面主导动作。内容类型负责选择节拍与覆盖方式；开场钩子、结尾悬念属于位置标签，应与内容类型叠用，不能用它们替代对话、打斗等内容判断。

## 逐项定义

### 1. `dialogue` 对话（两人静态）

**一句话定义：** 两人在同一空间以有来有回的台词交换信息、试探态度或改变关系。

**识别信号：** 双方位置基本稳定；台词承担主要推进；局面变化来自获知、判断、让步或拒绝。

**相邻区分：** 与 `confrontation` 相比，对话仍有可继续的信息交换，压力未必已经锁死；争执对峙则围绕不相容要求升级，单靠解释无法收场。电话两端分开时优先归 `phone-call`。

### 2. `establishing` 环境建立 / 定场

**一句话定义：** 用连续空间镜头说明地点、时间、尺度、入口和人物所处位置。

**识别信号：** 先交代大环境再落到人物；强调空间布局和通行方向；没有独立发生的冲突或信息翻转。

**相邻区分：** 与 `opening-hook` 相比，定场先让观众认识空间，钩子则必须立刻抛出不正常状态或待解问题。与 `montage` 相比，定场通常停留在一个连续环境中。

### 3. `opening-hook` 开场钩子

**一句话定义：** 在片头或集首迅速制造异常、威胁、损失或强欲望，让观众追问接下来会发生什么。

**识别信号：** 事件位于最前几个镜头；画面或台词立即打破常态；留下明确但尚未回答的问题。

**相邻区分：** 与 `establishing` 相比，钩子以异常和问题为先，地理信息可以后补。与 `cliffhanger` 相比，开场钩子启动本段叙事，结尾悬念则在高风险动作中途截断。

### 4. `cliffhanger` 结尾悬念

**一句话定义：** 在高风险选择、威胁或行动结果即将出现时结束，迫使观众期待下一段。

**识别信号：** 位于片尾或集尾；危险、选择或后果已经逼近；最后画面有意不给出结果。

**相邻区分：** 与 `twist` 相比，反转通常先给观众一个可重读前文的新解释；结尾悬念强调结果被截断。若镜头同时包含反转和截断，应标明主类型，并把另一个作为次标签处理。

### 5. `confrontation` 争执对峙

**一句话定义：** 两人或小群体围绕不可同时满足的要求互相施压，冲突停留在语言、姿态和边界试探。

**识别信号：** 双方各自坚持明确诉求；距离、高低位和语气逐步升级；出现最后通牒、拒绝或离场威胁。

**相邻区分：** 与 `dialogue` 相比，双方已经从交换信息转入逼迫选择；与 `fight` 相比，还没有形成持续的实体攻防。跨桌摔杯但没有接触，仍属对峙；一旦以身体阻断或击中对方推进局面，改判打斗。

### 6. `fight` 打斗

**一句话定义：** 以可见的身体或器械攻防推进的近身冲突，目标、阻挡、受击和反制依次改变局面。

**识别信号：** 出现实质接触、格挡、闪避、摔倒或逼退；前一招改变下一招的条件；本场后距离、伤势或主动权发生变化。

**相邻区分：** 与 `confrontation` 相比，冲突已进入身体或器械交锋；与 `chase` 相比，打斗围绕接触与争夺，追逐围绕拉开或缩短距离。若人物边跑边打，以主要戏剧任务决定类型。

### 7. `chase` 追逐

**一句话定义：** 一方持续追赶，另一方持续逃离或甩脱，空间移动本身推动叙事。

**识别信号：** 追者与逃者目标清楚；路线、拐角、障碍和距离不断变化；本场变化通常是从追到脱身、拦截或被迫接战。

**相邻区分：** 与 `fight` 相比，双方大部分时间不接触，胜负首先由距离决定。与 `montage` 相比，追逐有连续时空和不断更新的空间关系，不是无因果的快闪集合。

### 8. `reveal` 悬疑揭示

**一句话定义：** 隐藏的人、物件、身份或因果关系被看见并得到确认，观众的认知随之增加。

**识别信号：** 此前埋有线索或疑问；镜头通过打开、对焦、对比或证词把答案呈现出来；揭晓后至少一个判断被修正。

**相邻区分：** 与 `twist` 相比，揭示通常是补上一块此前缺失的事实，原有前提仍大致成立；反转则要让观众重新解释已发生的事。与 `process-closeup` 相比，揭示的核心是认知变化，过程细节只是证据。

### 9. `twist` 反转

**一句话定义：** 一项新证据或行动改变此前事实的含义，迫使观众重读前文。

**识别信号：** 前文已有可回看的误导或遗漏；新信息不是简单增加，而是推翻或重排既有因果；揭示后人物目标或阵营关系随之换位。

**相邻区分：** 与 `reveal` 相比，反转必须改变解释框架，单纯发现秘密只算揭示。与 `cliffhanger` 相比，反转可以给出完整新解释，结尾悬念则把后果留到下一段。

### 10. `intimacy` 告白 / 亲密

**一句话定义：** 两人通过靠近、触碰、告白或照料，让感情状态发生可观察的变化。

**识别信号：** 动作重点在距离、触碰、呼吸和眼神；双方或一方承担被拒绝的风险；身体靠近改变了关系定义。

**相邻区分：** 与 `dialogue` 相比，台词可以很少，关键在安全距离被主动改变；与 `confrontation` 相比，压力来自暴露真心而非争夺胜负。只有信息交换、没有关系靠近时仍归对话。

### 11. `monologue` 情感独白 / 内心戏

**一句话定义：** 单个角色向自己或画外对象持续表达内心判断，外部回应不是推进主力。

**识别信号：** 一人主导言语或思绪；画面可用背影、物件、空镜和微动作承载情绪；重点是从压抑到松动或决断的内在转折。

**相邻区分：** 与 `dialogue` 相比，没有交替回应来改变话语方向；与 `phone-call` 相比，不存在另一端的实时说话者。若角色实际操作一项技艺并完成步骤，优先归 `process-closeup`。

### 12. `phone-call` 电话 / 远程对话

**一句话定义：** 两人或两端通过电话、语音或视频连线交换信息，空间被通信设备切开。

**识别信号：** 声音经设备传来；两端处于不同空间，或只有一端出现在画面；挂断、信号中断、延迟和界面操作会影响信息。

**相邻区分：** 与 `dialogue` 相比，双方不在同一物理空间，剪辑需要在两端和共同听感之间组织；与 `monologue` 相比，另一端会实时回应。若只是旁白读出电话内容而没有另一端反应，可归独白或讲解。

### 13. `flashback` 回忆闪回

**一句话定义：** 叙事暂时进入过去时空，用一段可演出的往事解释现在的选择、关系或创伤。

**识别信号：** 时间标记、造型、光线、画质或声音明显切换；人物知道未来而画面中的人物不知道；回到现在后有认知或情绪回声。

**相邻区分：** 与 `montage` 相比，闪回通常保留一个连续过去场景和人物行动；蒙太奇是跨时间碎片的压缩。与 `reveal` 相比，闪回提供过去经验，只有新证据改写当前理解时才同时构成揭示。

### 14. `process-closeup` 工艺操作 / 动作特写（P01 类）

**一句话定义：** 用连续近距离镜头展示一项手艺、维修或精密操作的步骤、接触和完成结果。

**识别信号：** 手、工具和材料占主导；步骤有先后和物理约束；观众能看见操作如何改变物件状态。

**相邻区分：** 与 `montage` 相比，过程镜围绕同一任务逐段完成，不以跳跃压缩为主；与 `explainer` 相比，先展示怎么做，只有目的转为讲清原理时才归讲解。对话中的手部插入若只为承接一句话，仍归对应对话场。

### 15. `ensemble` 群戏

**一句话定义：** 三人以上的角色在同一戏剧单元中争夺注意力和决策权，关系网共同推动场面变化。

**识别信号：** 至少三人的立场或利益互相牵制；台词、走位和反应在多人之间转移；群体决定或阵营变化决定场面结果。

**相邻区分：** 与 `dialogue` 相比，不止一对人交换信息；与 `montage` 相比，群戏在相对连续的空间与时间中展开。多人打斗若核心是攻防因果，仍归 `fight`；群戏强调谁结盟、谁沉默、谁改变立场。

### 16. `montage` 过场蒙太奇

**一句话定义：** 用多段短画面压缩时间、地点或状态变化，跳过重复过程并连接前后剧情。

**识别信号：** 多次跳时或跳地；镜头之间靠动作、形状、声音或主题连接；单镜不要求完整因果，但整组必须产生清楚变化。

**相邻区分：** 与 `establishing` 相比，蒙太奇展示变化过程；与 `flashback` 相比，它不一定回到单一过去场景；与 `process-closeup` 相比，它允许跳过关键步骤。若所有镜头只在交代同一空间，应归定场。

### 17. `explainer` 讲解科普（竖屏）

**一句话定义：** 用示意、对照或演示把机制、步骤或道理讲清楚，观众以获得理解为主要回报。

**识别信号：** 信息按问题、原理、例子或步骤组织；画面需要辅助说明关系；台词或旁白承担定义和因果解释。

**相邻区分：** 与 `monologue` 相比，讲解追求可验证的理解，不以个人情绪为主；与 `process-closeup` 相比，操作可以只作演示，核心是让观众明白为什么。剧情对话顺带解释少量背景，不单独归讲解。

### 18. `scare` 惊吓 / 恐怖

**一句话定义：** 用威胁逼近、异常显现或突然冲击制造恐惧，并让角色或观众进入警戒状态。

**识别信号：** 负空间、视听预兆和突然变化共同施压；威胁可能尚未被完全解释；本场后人物开始躲避、调查或逃离。

**相邻区分：** 与 `reveal` 相比，惊吓首先制造即时威胁，答案可以暂时缺席；与 `cliffhanger` 相比，惊吓可以在场内完成爆发，结尾悬念则把结果留到下一段。完全安静但持续可疑、尚未爆发的段落，可按悬疑揭示的铺垫节拍处理。

## 建议增删

- **不建议合并现有 18 类。** `dialogue` 与 `confrontation`、`reveal` 与 `twist`、`phone-call` 与 `monologue` 都有可操作的拍法差异，合并后容易把节拍、机位和声音策略混在一起。
- **建议新增 `investigation`（调查 / 搜索）作为候选。** 这类戏的核心是人物在不确定中搜索、核对和排除假设，结果尚未确认，和已得到答案的 `reveal`、单纯展示手艺的 `process-closeup` 都不同。若作者认为现有 `reveal` 的铺垫节拍足够覆盖搜索过程，可以不采纳。
- **建议把 `opening-hook`、`cliffhanger` 作为可叠加的位置标签管理。** 它们与对话、打斗、揭示等空间或任务类型不在同一维度；当前单一主类型容易让“开场打斗”只能二选一。是否调整契约由作者决定。

### 19. `investigation` 调查 / 搜索（新增）

**一句话定义：** 角色在信息不完整、结论尚未确认时，通过查找、核对、比对和排除假设，逐步缩小范围并逼近答案。

**识别信号：** 角色主动搜检空间、物件、记录或证人；每次得到的信息只缩小范围，不直接给出答案；场面里出现假设、验证、推翻或暂时搁置的判断链；本场结束时可能只确认部分事实，或停在新阻碍前。

**相邻区分：** 与 `reveal` 相比，调查停在答案确认之前，揭示才把答案交给观众并改变认知；与 `process-closeup` 相比，调查的动作服务于判断和排除，工艺镜服务于完成 1 项操作；与 `montage` 相比，调查保留连续时空里的搜索、核对和停顿，蒙太奇用跳跃片段压缩过程。调查得到的新事实若只是补全信息，仍归调查；只有当它推翻原有解释时，才叠加 `twist`。
