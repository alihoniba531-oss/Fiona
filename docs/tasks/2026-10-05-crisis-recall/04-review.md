1. 新规则把大量日常话从「无」升成「高危」，例如：
   - 「我们各自尽力吧」；
   - 「火锅要烧炭吗」；

### [spec-compliance] M2：possible 级的新兜底规则缺少主语和边界，日常话被升为 possible，同句的工具请求被拦掉（核实：成立）

- **位置**：backend/safety.py:97（还有 :96），结合 backend/services/chat_service.py:1023 的 skip_tools
- **证据**：:97 `不想(?:再)?(?:醒来|撑了)` 不要求第一人称，「再」也是可选的：

- §7 A6 要求日常句的高危数和非 None 数都不得比基线多。
- 对用户的实际伤害：判成 high 会进入危机分支。前端会先收到 {"crisis": true}，回复改用危机指引，工具和待补参数都会被跳过。一位抱怨给孩子或猫喂药的家长会收到自杀干预式的回复。这明显误伤了日常功能，不是轻微问题。

三、修起来不难，规格语料并不需要这么宽
- 我在内存里用补丁替换了 _METHOD_QUERY，没有改任何文件。替换后的写法：

二、这是本单新写的规则，不是遗留问题。git diff 显示，safety.py:76 的「想跳」规则、:81 的「药备好…结束」规则、:140 的「也想跟他走」规则，都是本单新增的，所以在本单范围内。规格 §3.1 明确要求「新增的规则要覆盖『现象』，不能只覆盖语料里的具体句子」。这三条规则用 `(?=$|[,，。；;!?！？])` 把匹配钉死在句尾或标点前，实际上只覆盖语料原句，换个语气词就失效。这正是 §3.1 禁止的写法，也是 A6 盲测要抓的问题。

三、伤害不轻。被判 None 的句子都是明确的自杀表达：不给热线，不进危机分支。会话里挂着待补参数时，这句话还会被当成参数值送进工具，规格 §2 第 1 条描述的就是这个风险。按复核口径，这属于「行为错误、让用户处境更危险」。

四、我找到的反驳理由都不够分量。
1. 这些变体在基线上也是 None，不算退步。但本单的目标就是提高召回，而规则是本单新写的，不满足 §3.1 的硬性要求。
2. 前瞻的用途是挡住「跳舞 / 跳绳 / 跳伞 / 结束疗程」。我试了一个放宽的版本：`(?=(?:了|啊|呀|呢|吧|啦|嘛|哦)*(?:$|[…~～.。,，；;!?！？]))`。以下句子仍判 None：「我在天台上，想跳舞」「我在楼顶，想跳绳」「站在桥上想跳伞了」「我在桥上想跳了一段舞」「药都准备好了，今晚就结束疗程」「……结束了这个疗程」「我在楼顶健身房，想跳操了」。可见允许语气词和省略号不会引入新的误报类型。
3. 「楼顶有个蹦床，好想跳」「窗户外面的小鸟好想跳」在现有规则下已经判 high。可见句尾锚定本来就挡不住这类误报，误报是 `.{0,8}` 跨逗号造成的，和语气词无关。

五、需要降级的部分。
- 地点词表要补「桥边 / 窗台 / 阳台 / 窗边」，以及要覆盖「想往下跳」：这两项规格语料没有给出，基线同样是 None。本单只新增了「天台」，原有的「楼上 / 楼顶 / 窗户 / 桥上」是旧词表。这两项应归「可优化」。
- 「跟他走了」只判 possible：仍然会追加热线，也会拦住工具，伤害比判 None 轻。但它同样是本单新规则的句尾锚定问题，可以和上面的主问题一起修。

结论：real=true，不降级。必须修复的范围是：safety.py:76、:81、:140 三处前瞻要允许句末语气词（了 / 啊 / 呀 / 呢 / 吧 / 啦），以及省略号、波浪号；「了」后面还要允许接标点。地点词表扩充和「想往下跳」归可优化。

   - 有几句证据偏弱。"I took all my meds" 常见的意思是按医嘱把今天的药吃完了。我顺手测了 "I took all my pills today like the doctor said"，当前已经判 high，是误报，只是规格原句本身就要求判 high。所以 fix_hint 里把 meds/medication 也纳入、把 "every" 也算进去的做法，会让日常话判得更高，违反 §3.3 和 A6 对日常语料的约束，修复时不能照抄。"tonight I end it all"、"thinking about ending it all" 也不是最典型的说法。
   - 用户主要说中文，英文召回的分量比中文轻。

上面这几句即使全部去掉，"I just want to end it all"、"I just took all my pills"、"I swallowed all my pills"、"I took a whole bottle of pills"、"I am going to hang myself"、"I will hang myself"、"I think about killing myself every day" 也足以说明违反了 §3.1，而且会让高风险用户拿不到热线、话被送进工具。所以不该降级。
