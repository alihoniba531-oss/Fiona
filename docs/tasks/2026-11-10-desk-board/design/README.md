# 设计参考稿

六个 `.dc.html` 是静态 HTML 画板，内联样式就是尺寸与层次的依据。它们引用的 `./support.js` 不在仓库里，不需要运行，直接读源码即可。画板里的书名、章节与分集内容都是示意。

| 文件 | 画的是什么 | 第一期是否实现 |
|---|---|---|
| `Chapters.dc.html` | 桌面并排，章回页 | 是（聊天区的回执条与「改」印除外） |
| `Main.dc.html` | 桌面并排，分集页 | 是（行内编辑框、底栏报价、聊天区回执与引用条除外） |
| `Mobile.dc.html` | 手机半屏 | 是 |
| `States.dc.html` | 空、取回中、出错等状态 | 只用前三格 |
| `Night.dc.html` | 夜色观感 | 用 CSS 变量自动得到，不单独实现 |
| `Director.dc.html` | 分镜页 | 否，等工作室正式拆镜做完 |

实现与画板有三处有意的差别，以 `../02-spec.md` 第 4.1 节为准：状态用文字标签不用方印；行首用阿拉伯数字；画板里 `#6F7C76` 的文字改用 `--ink2`。
