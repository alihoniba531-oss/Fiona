## 必须修复（完整阅读 04-review.md 对应条目的证据与建议）

### R1 语境剥离把第一人称危机降级

`safety.py` 的语境/查询剥离规则不得吞掉句中的第一人称危机表达，方法类询问一律 high。下列句子**必须为 high**：
`我妈妈走了我也不想活了`、`我对象跟我分手了我想死`、`我孩子没了我想死`、`我朋友都不理我了我想自杀`、`我想写遗书然后自杀`、`我想问你我是不是该自杀`、`我想了解怎么自杀最快`、`我看看哪种自杀方式最快`、`帮我查一下怎么割腕不疼`。
并补行为测试：`帮我查一下怎么割腕不疼` 的首事件是 `{"crisis": true}`，且 `recognize_intent`、`execute_intent` 都未被调用。

### R2 无主语、正在进行的自伤与过量服药降级

下列句子**必须为 high**：
`不想活了`、`不想再活了`、`活不下去了`、`想自杀`、`打算自杀`、`准备自杀`、`真的想自杀`、`想轻生`、`活着没意思，不如死了`、`我割腕了`、`我在割腕`、`我刚割腕了`、`吃了一整瓶安眠药`、`吞了一把安眠药`、`累死了不想活了`、`我想结束生命`、`我在考虑结束生命`。
下列句子**至少为 possible**：`活着没意思`、`我累想死了`、`今天好累想死`、`我真的撑不下去了`、`晚安，永别了`、`明天就不在了`。
补行为测试：`我割腕了`、`吃了一整瓶安眠药` 首事件 `{"crisis": true}`，发往模型的 system prompt 以 `CRISIS_GUIDANCE` 结尾。

### R3 「要死」误报

恢复「要死」后不接「了」的限制，并排除第三方主语。下列句子**必须为 None**：
`我爷爷快要死了`、`我妈快要死了`、`我觉得他要死了`、`我的猫要死了`、`我狗快要死了`、`我怕我妈要死了`、`我要死了`、`我快要死了`、`我妈快要死了，我好难过`。
补行为测试：`我妈快要死了，我好难过` 首事件不是 `{"crisis": true}`，`recognize_intent` 被调用一次，prompt 不含 `CRISIS_GUIDANCE`，事件中不含 `CRISIS_RESOURCE_NOTE`。

### 三级夹具的总约束

- 原规格 T2.1 的全部 high / possible / None 夹具必须继续通过（例如 `帮我查下割腕的急救方法`、`他说他不想活了，我该怎么劝`、`今天新闻说有人跳楼了`、`安眠药吃多少会有危险`、`让我去死吧哈哈哈哈` 仍为 possible；`我困得要死`、`我要死磕这个bug`、`《自杀小队》好看吗` 等仍为 None）。
- **新增「基线对照」参数化测试**：`git show ae026c9:backend/safety.py` 中 `detect_crisis` 判为 True 的全部测试夹具句子，以及本单 R1、R2 的句子，在新版里不得低于本单或原规格规定的级别；报告里给出「HEAD 为 True → 新版非 high」的完整清单，每条都必须是规格或本单明确要求降级的句子。
- 若某两条要求确实无法同时满足，按 02-spec 第 4 节停下来，列出冲突句子，其余照常完成。

### R4 WAL 下的回滚与恢复

`docs/DEPLOYMENT.md`「回滚与恢复」在 `systemctl stop fiona` 之后插入步骤：确认数据目录下 `fiona.db-wal`、`fiona.db-shm` 的处理（需要旧库未落盘数据时先 `PRAGMA wal_checkpoint(TRUNCATE)`，否则直接删除），再用 `.backup` 快照覆盖主文件；启动前 `PRAGMA integrity_check` 必须输出 `ok`，并确认属主为服务账号。`03-report.md` 的「需要人工确认」补一句该事实。
