# 返修单 第 2 轮（危机识别：修复引入的误报 + 同族漏判）

来源：`04-review-round2.md`（第二轮复核通过，但列出返修第 1 轮新增规则造成的回归）。规格作者判定：返修引入的「旧版不触发 → 新版判 high」属于回归，违反 `02-spec.md` 目标 2「日常口语不受影响」，本轮定向修复。原规格、`05-fix-round1.md` 的全部约束与夹具继续有效；**只允许修改 `backend/safety.py`、`backend/tests/test_beta_safety.py` 与本目录 `03-report.md`**。

## 必须修复

### F1 无主语规则误报（旧 None → 新 high）

下列句子**不得为 high**（期望 None；若你认为某句应为 possible，须在报告说明理由）：
`疫情结束一切恢复正常`、`比赛结束这一切就值了`、`项目结束一切顺利`、`考试结束这一切就都过去了`、`等这个项目结束一切都好了`、`你要去死吗`、`你这样还不如死了呢`、`他要去死我也拦不住`（此句可为 possible）、`我妈要死不活的躺着`。

要求：「结束…(生命|一切)」在没有「我/自己」前缀时，必须紧邻意图词（想/要/打算/准备/考虑/在）才判 high；「要去死」「不如死了」前紧邻第二、三人称（你/他/她/它）时不判 high；把「要死不活」加入日常表达排除。

### F2 同族漏判（旧 True → 新 possible，或两版都漏）

下列句子**必须为 high**：`刚吞了半瓶安眠药`、`我吞了半瓶安眠药`、`哪种安眠药吃了不会醒`、`我朋友跳楼了，我也想跳`。
下列句子**至少为 possible**：`刚吞了好多药`、`我吃了很多药`、`我觉得活着没什么意义`、`活着没有意义`。

### 不得回退

- `02-spec.md` T2.1、`05-fix-round1.md` R1/R2/R3 的全部夹具必须继续通过；
- 以下必须保持 high：`我想结束这一切`、`我想结束生命`、`我在考虑结束生命`、`不如死了算了`、`活着没意思，不如死了`、`我要去死了`、`我现在就想去死`；
- 把 F1、F2 全部句子并入参数化夹具；更新「基线对照」清单（`git show ae026c9:backend/safety.py`），报告里给出本轮前后变化的句子清单。
