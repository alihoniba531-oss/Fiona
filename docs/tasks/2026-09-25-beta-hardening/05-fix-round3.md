# 返修单 第 3 轮（最后一轮：危机识别的新增误报 + 语料护栏）

来源：`04-review-round2.md` 末尾「第三轮定向核验」（通过，但列出返修第 2 轮新增规则造成的误报）。**只允许修改 `backend/safety.py`、`backend/tests/test_beta_safety.py` 与本目录 `03-report.md`**。原规格及第 1、2 轮返修单的全部夹具继续有效，不得回退。

## 必须修复

### G1 安眠药日常问句被判 high

`安眠药` 不得作为通用方法名词出现在「怎么/如何/哪种/方式」类询问规则里；只有带致死语义时判 high（可参考复核给出的已验证写法：`(?:哪种|什么)?安眠药.{0,8}(?:不会醒|能死|致死|才能死|最快|多少.{0,3}(?:能|会)死)`）。下列句子**必须为 possible**（涉及药物，附资源但不劫持）：
`失眠怎么办，要不要吃安眠药`、`医生开的安眠药怎么吃才对`、`长期吃安眠药怎么戒掉`、`安眠药怎么买`、`哪种安眠药副作用小一点`、`安眠药和褪黑素哪种更温和`、`我妈失眠，哪种安眠药适合老人`。
`哪种安眠药吃了不会醒`、`刚吞了半瓶安眠药`、`吃了一整瓶安眠药` 必须仍为 high。

### G2 意图单字误中「现在/正在/只要/需要/主要/重要」

「在…结束」「要…结束」类意图匹配须排除上述双字词尾（可参考复核给出的已验证写法：`(?:想|打算|准备|考虑|(?<![现正实])在|(?<![只需重主])要)结束`）。下列句子**必须为 None**：
`疫情现在结束一切恢复正常`、`比赛现在结束一切都定了`、`现在结束一切都来不及了`、`只要结束一切都好说`、`需要结束一切重新开始`、`主要结束这一切的是他`。
`我想结束这一切`、`我在考虑结束生命`、`我打算结束这一切了`、`我要结束这一切` 必须仍为 high。

### G3 「想跳」只排除了跳舞

`我.{0,2}想跳` 须同时排除 `槽|伞|绳|远|高|舞`。`我朋友跳楼了，我也想跳槽` 必须**不为 high**；`我朋友跳楼了，我也想跳` 必须仍为 high。

## 语料护栏（新增测试，防止再打地鼠）

新增参数化测试 `test_everyday_corpus_never_high`：以下日常句**全部不得为 high**（None 或 possible 均可）；新增 `test_explicit_risk_corpus_always_high`：以下危机句**全部必须为 high**。以后任何规则改动都必须同时通过这两组。
