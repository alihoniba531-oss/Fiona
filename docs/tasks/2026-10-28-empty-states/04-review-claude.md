# Claude 多视角复核记录：空态与文案（第三批）

与千问 3.8 Max 的独立复核并行，Claude 另派只读工作流复核实现。每个视角是一个全新上下文的子代理：
- 只读工作树、不改文件、不起服务器、不用浏览器；
- 实验只在仓库外的临时目录里做（用 node / jsdom / 抽出函数喂假事件）。

两边结论由 Claude 合并裁决，必要时用真实浏览器实测确认。

## 第一轮：审 v1.1 交付（快照 `aa9aef9f6cc4699f`）

三个视角：runtime、ux、tests。

**判为必须修复，进入返修 R1**。前四条都在真实浏览器里用 HEAD 作对照量过：

1. 按住 Enter 往输入框插空行。`if (e.repeat) return;` 排在 `preventDefault()` 之前，三个视角都独立报了这一条。实测：打字后按住 Enter，输入框留下 4 个换行；在「聊聊今天」上按住 Enter，输入框变成「聊聊今天\n\n\n\n」。HEAD 上两种情况都为空或不变。
2. 嵌入抽屉页眉塌成 0 高。h1 是 sr-only，书斋在加载、刷新时上下跳 40px，工作室在权限返回时跳 40px。实测：说明文字的位置 80 → 40 → 80 → 40；HEAD 一直是 80。
3. 日期面静默写「不限」。键入出 5 位年份时，筛选已生效，日期面却写「不限」。实测：键入后值为 `61027-02-02`，日期面是「不限」。
4. 矮屏下匹配页按钮被裁。`mt-10` 配 `max-h-full`，滚动框底部落在父容器外。实测：820×360 下按钮底边 303，超出容器底边 287。
5. 日期框的可访问名称不含可见标签「从」「到」（WCAG 2.5.3）。
6. Claude 提示句里的「本轮」，在设置页没有指代对象。
7. 身份 hook 注释的说法与代码不符。
8. 新测试拦不住几类错误实现：
   - 身份找回失败的路径没测到；
   - 开场「绝不自动发送」用黑名单判断；
   - 10 处接线只查子串；
   - 隐私第一段可以被包进条件里；
   - 书斋测试分不清留下的是哪一个「新建一本」；
   - 另有 showPicker 计数、语音测试缺超时、文档断言过严等小项。

**降为可优化项，交作者决定**：
- 日期框透明后，键盘 Tab 停在看不见的分段上。实测鼠标和触屏点击也匹配 `:focus-visible`，所以不能用「键盘聚焦时显出原生框」来解决。
- 401 跳转前先闪一下登录提示；另一个标签清掉用户名、Cookie 仍有效时，会先显示登录提示。这两条都写进已知局限。
- 语音气泡为首次提示让位 4 秒、开场按钮禁用时没有说明、日期 chip 没有悬停提示、隐私段落的 `aria-describedby`、iOS 上 `focus()` 在 rAF 里可能不弹键盘等。

**同一轮千问的结论**：只报了报告占位符这一项必须修复。它看到了按住 Enter 后的实测值，但以「规格禁止改动其余部分」为由判为无害。

## 第二轮：核验返修 R1（快照 `7c4aa5ca5c3c3510`）

三个视角：runtime、a11y-copy、tests。

**返修 R1 的各项判为已修好**，并给出了证据：
- `handleKeyDown`：抽出 HEAD、v1.1、R1 三版的函数体，喂了 5 类事件序列。R1 每个事件是否 preventDefault 都与 HEAD 相同，唯一差别是自动重复不再发送。
- 页眉行：构建产物里 `.min-h-10` 与按钮高度合起来，嵌入行恒为 40px；独立页的 h1 仍是 45px（书斋）和 42px（工作室）。
- 日期面：用真实的 `lib/beijingTime.ts` 跑了 12 个输入，无法解析的值都显示原值。
- 匹配区：按盒模型推，静止时的位置与 v1.1 相同，矮屏下按钮在容器内。
- 测试加固：在仓库外的副本里做了 11 个变异，全部变红。

**判为必须修复，进入返修 R2**：
- R1 改 `page.tsx` 时去掉了文件开头的 UTF-8 BOM。这违反返修单「page.tsx 其余一字不动」，diff 多出第 1 行的 hunk，报告里「其余未动」的说法也就不成立了。运行时没有影响。
- 同轮千问把它列为可优化项。Claude 取严：补回只是三个字节，补回后最终 diff 只剩该有的改动。

**降为可优化项**：
- 测试缺口：日期框两个 aria-label 对调时测试拦不住；隐私第一段连同 Claude 提示一起包进 `{needsKey && <>…</>}` 时拦不住；给开场按钮外层 `div` 加 `onKeyDown` 时拦不住。这几种都是假想中的错误写法，当前实现没有这些问题。
- `test_empty_states_identity.py` 有一处 `read_text()` 没有指定 encoding。
- 书斋抽屉 0 本书时顶部有一条 40px 空带，位置就是 HEAD 上「新建一本」按钮原来的位置。这是 v1.2 为了不跳动做的取舍，版式要不要改由作者看截图决定。

**同一轮千问的结论**：通过，没有必须修复项。19 个变异全部被抓到；BOM 列为可优化项。
