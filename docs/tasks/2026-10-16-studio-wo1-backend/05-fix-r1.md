**R1-6 删号清理显式区分工作室目录**

- `delete_uploaded_files` 只对 `studio:` 前缀走目录删除分支。之前对 `/uploads/` 根据 resolve 结果去推断的特判要删掉。
- 目录删除仍须满足：在工作室根目录之内、不是根目录本身、不是符号链接、确实是目录。
- 已入队的旧格式条目（绝对路径）也要能处理：在根目录之内的照删，不在根内的判失败。
- 旧的 `/uploads/x.png` 文件清理行为保持不变。
- 原有的安全测试全部保留，再补上新格式的测试。

**R1-7 删号时不阻塞事件循环**
