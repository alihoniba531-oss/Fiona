# WO1 真实服务器验收（2026-10-16）

**环境**：
- 隔离后端端口 8061，从 worktree 代码启动。
- 临时数据库和临时工作室目录；环境文件为空，`DEV_MODE=1`；工作室只对本机回环开放开发头（`FIONA_STUDIO_REQUIRE_JWT=0`）。
- 万相用作者 `~/.zshrc` 里的 Key。
- 没有碰本机 8010 端口上的服务和真实数据库。

**花费**：作者批准只跑万相 480P 5 秒，上限 ¥1.50；**实际结算 ¥1.50**。Seedance 没有跑。

| 步骤 | 结果 |
|---|---|
| `/health` | 200 `{"status":"ok"}`（包括 studio_storage 检查项） |
| 作者 `GET /studio/access` | 200；日上限 300，单次上限 100，万相和 Seedance 在途上限各 3；当日占用 0 |
| 非作者访问、未登录访问 | 都返回 404 |
| 建项目（9:16），上传首帧 S07.png | 201；asset 记录宽高 941×1672 |
| 报价：万相 480P、5 秒、带音频 | ¥1.05–1.50，15 分钟有效 |
| 确认 | 生成 1 个任务；**再次确认返回 409** |
| 调度器提交 | 2 秒内从 queued 变为 submitted，拿到 task_id `28b6700c-…` |
| **中途重启服务**（任务处于 running 时） | 重启后任务仍是 running，**task_id 不变**，继续轮询，没有重新提交 |
| 完成 | 重启后约 51 秒变为 succeeded，约 61 秒完成下载，`actual_cny=1.5`，生成结果 asset |
| 文件 `Range: bytes=0-1023` | **206**，`content-range: bytes 0-1023/3288074`，`cache-control: private, no-store`，`video/mp4` |
| 成片 ffprobe | 480×852、30fps、带音轨、5.04 秒 |
| 当日占用 | `committed_cny=1.5`，`remaining_cny=298.5` |
| 非作者访问成片文件 | 404 |
| 任务接口是否泄露签名地址 | 没有（返回中不含 Signature、Expires 或 OSS 地址） |
| 服务端日志 | 没有任何工作室相关的输出（正常情况下工作室不打日志） |

**小问题（留给 WO2 处理）**：报价和任务的返回里，同时带着原始 JSON 字符串字段（`items_json`、`params_json`、`usage_json`）和解析后的字段，有重复。WO2 前端只用解析后的字段；接口是否瘦身，到 WO2 再定。
