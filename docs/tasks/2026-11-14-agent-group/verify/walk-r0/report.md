# 东南亚AI短剧出海调研与起步方案

## 结论与建议

1. 建议做，但仅限纯供片轻资产试水。主人团队三人、预算紧，不具备自建平台或本地买量能力，把内容卖给已落地的分发平台是唯一现实路径[S144][S151]。
2. 前提条件必须严守：三个月总投入控制在20万元人民币以内，不注册海外主体，不自行投流，接受98.7%项目半年不回本的行业现实[S162]。
3. 印尼是首选市场，下载量大但单次下载收入仅1.53美元，不能指望内购爆发，题材须切校园青春、家庭伦理等本地偏好[S17][S213]。
4. AI确实压低了制作门槛，理论下限可至350元/分钟，但算力抽卡和返工成本不容忽视，技术降本不等于商业壁垒[S39][S140]。
5. 合规风险可通过不碰终端用户规避，只要只做供应商、不在印尼直接运营APP，即可绕开PSE注册和高昂的外资公司门槛[S167][S170]。

## 东南亚短剧市场概况与AI短剧现状

判断：印尼是东南亚最大的增量市场，流量充沛但变现效率低；AI已成为主流生产方式，供给端极度拥挤。

印尼在2025年上半年短剧下载量达1200万次，位居全球第一，东南亚内购占比升至10%且涨幅最高[S23][S112]。然而，印尼的单次下载收入（RPD）仅为1.53美元，远低于美国的5.00美元，整个东南亚市场以广告变现（IAA）为主，用户付费意愿弱[S17][S30]。泰国增长较快，短视频使用强度高，但整体体量偏小，只能做补充市场[S214][S212]。

题材上，东南亚偏好校园青春、家庭伦理、穿越逆袭，北美那套霸总甜宠不能直接搬[S213]。在供给侧，AI已经重塑了产能结构，目前出海微短剧中AI剧占比高达61.39%，借助AI多语种译制能力，6至7小时即可完成多版本上线[S16][S32]。这印证了主人的技术背景优势，但也意味着单纯的制作成本优势极易被抹平。更严峻的是投流成本的攀升速度远超收入：2026上半年海外广告素材投放量同比增长324%，而内购收入仅增长约13%[S18][S19]。

## AI短剧制作流程与单集成本拆解

判断：按80集、每集1.5分钟的标准规格测算，单部现金成本区间为3至6万元，所谓5000元总包对应极简模板化流程，不宜作为常规预算依据。

统一假设前提：单部短剧共80集，每集1.5分钟，总时长120分钟。面向印尼市场，采用AI生成画面加印尼语配音模式。工具链假设为：文生图或文生视频模型（如Midjourney、Kling等类别）、AI翻译工具、AI语音合成（TTS）配音工具、自动化剪辑脚本。

| 成本口径 | 估算区间 | 说明 |
| :--- | :--- | :--- |
| 单分钟理论下限 | 350至500元[S39][S38] | 假设使用主流文生图或视频模型批量出图，不含废稿成本。 |
| 单分钟含抽卡成本 | 约650至800元（推断） | 为达到可用效果需反复生成筛选，算力抽卡消耗近300元/分钟[S138][S140]。加上基础配音与译制约50元/分钟[S38]。 |
| 单集成本（1.5分钟） | 525至1200元（推断） | 按上述单分钟区间乘以1.5分钟得出。 |
| 80集总成本（常规） | 3至6万元（推断） | 按含抽卡与返工的650至800元/分钟乘以120分钟，并预留审核修改余量。 |
| 80集总成本（极限） | 约5000元[S160][S144] | 行业极限压缩报价，通常对应极简画风与高度模板化流程，不适合追求过审率的常规交付。 |

关于5000元与650至800元/分钟的矛盾解释：5000元是标准化模板跑通的极端情况，省去了大量抽卡试错和人工调优[S144]；而650至800元/分钟是包含算力浪费和基础本地化的实际作业成本。主人团队缺乏影视经验，初期很难一步到位跑出5000元的极限流程，建议按3至6万元准备单部预算。

需要向主人明确：上述表格中，350至500元/分钟[S39]和50元/分钟译制[S38]为公开报价数据；含抽卡的650至800元/分钟、单集成本及3至6万元总成本为基于来源数据的推断。此外，平台模型迭代可能导致旧产出被判为陈旧而拒收，增加返工成本[S163]。

## 变现模式与头部产品收入水平参考

判断：已跑通的变现模式分为IAP和IAA两种，但利润集中在掌握流量的分发端，内容供应商处于弱势地位。

1. IAP（应用内付费解锁）：北美市场表现较好，但在东南亚水土不服。东南亚ARPU值仅为北美的五分之一[S52]。所谓「20天回本、首日ROI 0.8」的行业神话来自北美买量模型，不能直接套用到印尼等市场[S5]。
2. IAA（广告变现）：东南亚短剧的主流模式。通过免费观看加插片广告获利，但eCPM受当地广告主预算限制，天花板较低。

从行业整体回报来看，情况不容乐观。数据显示，98.7%的短剧项目半年内无法回本，仅有1.3%能跑通盈利模型[S46][S162]。头部玩家依靠混合变现月流水可近1亿美元[S144][S151]，但这依赖庞大的买量资金和本地化运营团队。对于主人的三人团队而言，做内容供应商比做平台现实得多，利润空间取决于能否拿到平台的稳定分成。

## 内容与技术合规风险清单

判断：印尼对数字平台和AI内容的监管正在收紧，但纯供片模式可将部分合规责任转移给采购平台。

| 国家 | 合规要求与限制条款 | 对主人的影响 |
| :--- | :--- | :--- |
| 印尼 | 2026年4月起强制要求电子系统提供者完成PSE注册，未注册将被禁用本地支付网关与CDN；审批约需47个工作日，AI内容审查再延约21个工作日[S167]。 | 若自行上架APP则必须面对此门槛，耗时且存在下架风险。 |
| 印尼 | 设立外资公司（PT PMA）实缴需25亿印尼盾并锁定12个月，单项目最低投资额达100亿印尼盾[S170][S172]；2026年起须用KBLI 2025版精准匹配AI业务类别注册[S171]。 | 资金门槛极高，直接吞掉20万预算。 |

## 综合判断：做还是不做

判断：做。

适用前提：
1. 团队规模保持在三人以内，发挥主人给中小企业做AI智能体的技术长板，不涉足重运营的本地推广与客服。
2. 绝对不注册印尼PT PMA等本地主体，不承担PSE合规成本。
3. 不自建APP，不自行买量投流，放弃暴利幻想，仅作为内容供应商向成熟平台供片。
4. 前三个月总投入严格控制在20万元人民币以内，将其视为测试费而非必赢的投资。
5. 3个月无签约或首笔回款即止损。

反方观点认为现有材料更支持不做：东南亚RPD低、投流素材增324%但收入仅增13%、98.7%半年不回本，AI降本只是打烂了供给端并未形成护城河；所谓轻资产供片并未证明能回款，也未证明合规免责；拿不到书面采购价、账期和首笔回款路径，就不该批量生产。这些担忧完全成立。因此，本结论的核心逻辑不是东南亚短剧好赚钱，而是利用主人的AI技术优势，以极低的沉没成本去验证一个概率游戏。如果不把预算锁死在20万以内、不把账期和拒审率摸清，就不该入场。

## 起步落地方案

预估前3个月总投入：控制在20万元人民币以内（主要为云算力、API调用及少量外包配音费用）。

第1个月：只做样片加BD拿书面意向
- 动作：确定目标平台（首选DramaBox），研究其招商过审标准。利用团队现有的AI智能体技术，搭建从剧本生成、分镜绘制到视频合成的自动化工作流。产出1至2部面向印尼市场的印尼语AI短剧样片（无需做满80集，先做前10集测试），提交平台审核或进行商务对接，目标是拿到书面的采购意向、明确的结算账期与回款路径。
- 核心验证指标：平台审核通过率、是否取得书面采购意向、单次审核反馈周期。

第2至3个月：按需制作与数据验证
- 动作：只有在第1个月拿到书面意向或明确签约路径后，才启动全量80集的制作。分析前期的拒审原因，调整提示词与工作流参数。交付后由平台自然分发，或由平台代投，严禁团队自行拿出预算在TikTok或Meta进行切片素材投放，确保与不买量前提一致。
- 核心验证指标：首笔回款金额、净回款除以现金成本的比值、账期天数。

上一版方案中曾提及拿出1万元在TikTok或Meta投放的动作，该具体金额及投放动作未见来源支撑，属团队推断，且违背主人不买量的前提，现已删除并改为平台自然分发或代投。

## 风险与不确定

1. 平台保底承诺的真实性存疑。DramaBox等公布的保底与分成数据多为招商宣传，缺乏实际结算验证，若最终按极低底价买断，单部数万元的成本也可能亏损。
2. 98.7%半年不回本的数据反映了行业的残酷性[S162]。AI降低了制作门槛，同时也导致内容严重同质化，平台随时可能因模型迭代将旧产出判定为陈旧而拒绝收录[S163]。
3. 成本拆解中的配音、版权及返修费用多为推断。若印尼语配音质量要求超出AI直出水平，需人工介入，单分钟成本将大幅上升。
4. 合规隔离的前提是平台方靠谱。若合作的分发平台自身未完成印尼PSE注册而在2026年被封禁，供应商的内容也将随之失去分发渠道。供片模式下的具体法律责任链条尚未完全查清。
5. 小团队议价权差，所谓轻资产供片尚未证明能稳定回款。如果第1个月拿不到书面采购价、账期和首笔回款路径，建议直接终止，剩余预算不予动用。
