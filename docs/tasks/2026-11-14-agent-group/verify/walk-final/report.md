# 面向东南亚市场的AI短剧出海调研报告

## 结论与建议

- 三人团队、20万预算下，不建议自建App或投流做AI短剧出海。行业超80%项目亏本，头部五平台占近八成收入，新进入者无议价空间[S196][S127]。
- 仅建议以极轻资产模式做内容授权或自然流量试单：不建海外主体、不投流，用TikTok免费分发测数据，凭完播率向ReelShort等平台询价授权（推断）。
- AI短剧产能已严重过剩，前10个月上线近55万部中94%为AI生成，靠堆量无法建立壁垒[S18][S19]。
- 印尼下载量大但ARPU低，泰国进下载前十却未进收入前十，两国均非变现主战场[S1][S41]。
- 现有公开资料在渠道商业接入、同口径收入、版权规则、承制采购四个关键环节均断链，起步方案本质是用低成本测试换取一手询单信息，而非成熟商业闭环（推断）。

## 东南亚短剧市场现状与AI应用趋势

判断：盘子大但ARPU低，AI供给严重过剩，小团队缺乏入场优势。

印尼是短剧增长最快的市场之一，2025年上半年贡献全球内购收入10%，6月下载量达1200万次居全球第一，但ARPPU仅约2.3美元/剧[S1][S231]。在出海整体格局中，印尼属于T2梯队，T1市场占出海内购收入87.47%，印尼和泰国并非收入主战场[S40]。泰国短视频生态活跃，TikTok Shop GMV全球第一，但短剧业务进下载前十却未进收入前十，说明泰国难变现[S119][S41]。题材偏好集中在甜宠、虐恋、复仇、霸总等强冲突爽剧，本地化方向明确[S2][S232]。

供给端呈红海特征。前10个月上线近55万部短剧中94%为AI生成，中国出海短剧中AI占比已达61.39%，而仅1.3%的新剧能达到5000万播放量的盈亏线[S18][S161]。头部五家平台占据海外短剧近八成收入，2026上半年应用内购买仅增10%，广告投放量却激增324%，变现高度依赖流量竞争[S160][S161]。

## 主流平台与分发渠道盘点

判断：公开上传可作免费验证，但商业接入的资质、分成、提现条件均无公开来源，不能视为闭环。

| 平台/渠道 | 类型 | 已知信息 |
|---|---|---|
| TikTok | 公开流量平台 | 千次播放收益约0.07美元[S26]；泰国TikTok Shop GMV全球第一，短视频生态活跃[S119] |

印尼、泰国的短剧分发以TikTok、YouTube Shorts的公开发布，以及ReelShort、DramaBox等中国主导的独立App为主，泰国尚未接入本地主流长视频平台[S139][S120]。ReelShort和DramaBox收入体量巨大，但三人团队只能尝试授权或承制供货[S127][S128]。

## AI短剧制作流程与成本拆解

判断：入门级单集成本低，但整剧叠加人工调优与隐性返工后并不便宜，且所用工具的备案状态需逐一核验。

入门级漫剧单集成本约50至200元，普通档整剧总成本在5至10万元之间[S52][S54]。成本差异主要来自规格不同：单集低价是入门漫剧估算，整剧高档含20%返工时可达20万元[S52][S54]。其中人工调优费用占总制作费的30%至40%，因返回失败带来的隐性返工成本约占10%至20%[S52][S54]。AI译制环节可降至每分钟50元，100集约12小时完成，但这仅覆盖译制，不含生成工具算力成本[S233]。

关于AI工具类别与备案状态：目前公开资料仅查到地方累计备案数量（如广东230款、北京325款），没有任何一款被点名说明属于短剧生成用途，无法直接核验目标工具是否已完成境内生成式AI备案[S287][S289]。实操中常用的工具类别包括文生图模型（如Midjourney、Stable Diffusion类）、图生视频模型（如Runway、Kling类）及语音合成工具。若使用未备案境外工具生成内容出海，仍受境内生成式AI管理办法管辖，存在追溯风险[S140][S141]。替代方案是选用已完成境内备案的国产多模态大模型API，但可能牺牲部分画面表现力并增加调用成本（推断）。

成本测算假设前提：按主人提供的三人团队配置，不含投流费用，仅计算AI算力、素材采购与人工调优的直接支出。行业平均单部毛利为负3962元，即便将成本压至5000元/120分钟也难以盈利[S161][S162]。投流占预算70%至80%，北美获客成本达5.28美元/人，九成靠投放起量的团队亏损，三人团队无法承接[S67]。

## 变现模式与收入水平参考

判断：IAA广告与自然流量分发是仅有的轻资产选项，但缺实际eCPM与创作者分成数据，无法测算回本周期。

模式一：IAA广告分成。IAA占海外短剧市场近半，东南亚增长快[S42][S236]。但印尼的实际eCPM与平台抽成后的结算门槛未公开，收入不可测算[S238][S236]。若仅按TikTok千次播放0.07美元计算，百万播放仅带来约70美元收入[S26]。

模式二：自然流量分发转内容授权。通过TikTok或YouTube Shorts免费分发积累完播率数据，再凭数据向ReelShort等平台询价买断或分成授权（推断）。

关于泰国运营商订阅模式的降级说明：泰国已有电信运营商小额订阅先例，如AIS 39泰铢/月、TrueID周卡69泰铢[S32]。但此模式属于支付通道参考，并未被验证为独立的短剧变现模式，因此从已跑通模式中剔除，仅作低投流变现的方向参考[S32]。

据主人提供，本次调研限定20万预算。按单部1至3万元成本倒推，若仅靠TikTok流量分成回本，首月需达到约203万至609万次播放，且未扣除平台抽成，这在自然流量下极难实现[S3]。

## 各国合规与版权风险提示

判断：印尼自营落地门槛远超预算，泰国有刑责风险，国内法规有追溯力，版权规则缺失。

| 国家 | 关键限制 |
|---|---|
| 印尼 | 强制AI内容标注且元数据须可追溯[S17]；做自营落地须设PT PMA，实缴下限25亿印尼盾，资金锁定12个月[S174][S175]；境外数字服务商须登记缴11%增值税[S78] |
| 泰国 | 无AI专门法，但恶意伪造音视频依《计算机犯罪法》第16条最高处5年监禁、20万泰铢罚款[S142]；PDPA已生效，AI训练用个人数据需明示同意[S83] |
| 越南 | 2026年8月起七项网络安全法令落地，最高罚款为本地营收5%，但短剧内容审核与版权专项规则公开资料未查到[S97] |
| 中国 | 用未备案境外AI工具生成内容出海，仍受境内生成式AI管理办法管辖[S140][S141] |

印尼25亿印尼盾实缴叠加本地实体运维，与三人团队20万人民币预算完全冲突，自营落地不建议做[S174][S175][S176]。泰国BOI虽有13年免税优惠，但需真实运营与本地雇佣方案，三人团队不适用[S259][S261]。

版权权属方面，AI生成内容的版权归属在印尼、泰国、越南均未见明确的专项规则，实操前须咨询当地律所（推断）。

- 泰国对境外数字服务商的增值税登记门槛未查到。

## 结论：做或不做的判断及依据

判断：重模式（自建App、投流、设海外主体）坚决不做；轻资产模式（内容授权或自然流量试单）可做有限验证，但需做好止损准备。

依据如下：
1. 财务模型不成立：行业超80%项目亏本，仅1.3%新剧过盈亏线，头部五平台占近八成收入，新进入者无议价空间[S196][S161][S160]。
2. 预算与合规冲突：印尼自营落地的实缴资本门槛远超20万人民币预算，且资金锁定12个月[S174][S175]。
3. 团队能力错配：投流占预算70%至80%，需要重运营，三人团队无法承接[S67]。
4. 供给过剩：AI短剧占出海总量61.39%，靠铺量无法突围[S161]。

适用前提：不投流、不建海外主体、只做供货或免费分发测试。若主人坚持要试，只能将单部预算压缩至1至3万元，纯靠自然流量测试内容接受度，并以能否获得平台询单作为唯一放大依据（推断）。涉及印尼、泰国的公司设立与税务合规事宜，建议咨询专业法律与财税人士。

## 起步方案建议

判断：以三个月为期，用极低成本换取一手市场反馈，不设具体播放量止损线，以询单和转化为准。

第一个月：产出样片与自然流量测试
- 选定甜宠或复仇等强冲突题材，用AI工具生成3至5集入门级漫剧样片，总成本控制在1万元以内[S2][S52]。
- 在TikTok开设目标国账号，发布切片内容，不投流。
- 核心观测指标为完播率与互动率，用于评估内容接受度，不以绝对播放量作为止损依据（推断）。

第二个月：凭数据询价与授权试探
- 汇总首月完播率与互动数据，以此作为商务筹码，主动联系ReelShort、DramaBox等平台的商务渠道，探询承制或授权的准入门槛与报价区间[S139]。
- 尝试优化第二部内容的脚本与画面调优，控制人工调优成本。
- 本月目标是获取至少一个采购方的初步反馈或样片要求，而非追求播放量增长。

第三个月：复盘决策与止损退出
- 若无任何采购方接单，或自然播放未获平台推荐算法倾斜，即止损退出，不再追加预算。
- 若有明确成交对象且报价能覆盖制作成本，再考虑是否动用剩余预算进行定向生产。

全程需注意：使用的AI生成工具须优先选择符合国内生成式AI管理办法备案要求的型号，避免出海内容被境内监管追溯[S140][S141]。所有涉及泰国《计算机犯罪法》与印尼AI标注的合规细节，在正式发布前须由专业人士审核[S142][S17]。

## 风险与不确定

- 现有证据足以否定自建App和投流，但不足以完成原任务的可做性判断。渠道接入、收入同口径、版权规则、承制采购四个关键环节都断链，所谓起步方案更多是用残缺行业数据劝退，不是经过验证的商业方案（推断）。
- 若要下结论，只能说重模式不做；轻资产承制或授权仍需一手询单，不能凭全球均值判死刑。三个月自然流量验证若没有明确的成交对象，大概率只是烧钱买教训。
- TikTok千次播放0.07美元的收益极低，IAA模式下印尼实际eCPM与结算门槛未公开，收入不可测算，回本周期无法准确预估[S26][S236]。
- 起步方案中的止损节点（如"无采购方接单即退出"）为基于三人团队约束的经验假设，非行业通用规则，实际操作中可能因沟通周期长而误判（推断）。
- AI生成内容的版权权属在东南亚多国尚属空白，若后续产生爆款，面临被抄袭却无法维权的法律盲区（推断）。
