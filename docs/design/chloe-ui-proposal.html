方向

Chloe 是每个人自己的分身。界面要像一台你拥有的仪器：精确、安静、只在需要的时候亮一盏灯。科技感来自等宽读数、1 像素的线、磨砂玻璃的层次和唯一一条会动的信号线，而不是发光、折射和扫描线。

一条线是分身的存在待命是平线上跑过的亮点，说话是波形，听你说是波形加红点。它是界面上唯一常动的东西。
磨砂玻璃，不发光外壳和卡片是半透明磨砂玻璃，透出底场和滚过的内容。1px 线、6/10px 圆角。没有折射、发光、切角、四角括号。
中文优先标签全部是中文。数字、时间、回合数、模型名用等宽读数。不用全大写英文眉标。
做减法每页一个主要动作。工具结果回到消息里，语音进输入区，三栏收成两栏。

磨砂玻璃

玻璃是「磨砂」不是「液态」：统一模糊、半透明、一层细颗粒，没有折射、湿润高光和发光。只用在两类地方：常驻外壳（导航栏、对话列表、对话头部、输入区、页面标题）和卡片（工具卡、生成图、名片、搭档卡、作品）。文字、按钮、标签、消息块不模糊。
