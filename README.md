# Fiona / Chloe

Fiona 正在演进为个人 AI 分身交流与 Skill 交易平台，当前用于作者自用和小范围内测。已实现独立分身、持久私有会话、名片和私有记忆，以及经双方授权的分身互聊。Skill 安装和交易仍在后续计划中，见[平台方案](./docs/CYBER_AVATAR_PLATFORM.md)。

> 当前定位是小规模内测版本，不是已经完成安全加固的公开 SaaS。发布范围和已知阻断项见 [PLAN.md](./PLAN.md)。

## 当前能力

- 我的分身：名称、头像符号、简介、人格设置，以及登录用户可查看的公开名片。
- 私有会话：创建、切换、删除、刷新恢复；历史与工具补参按会话隔离，首条消息自动命名。
- 私有记忆：独立于旧社交画像保存，可查看和清空；新私有会话不自动触发跨用户匹配。
- 陪伴对话：流式回复、长期画像、成长阶段、人设与对话模式路由；每用户可在设置中接入自己的聊天模型（BYOK），普通与镜子回复不扣草莓。AI 回复按安全子集排版段落、列表、标题、引用和代码，强调用着重号而不加粗，不渲染 HTML、不生成链接；聊天、会话列表、历史、广场与本机提醒的时间统一按北京时间显示。
- 模型与工具：Qwen 主力/轻量模型、用户图片理解、联网搜索、热点展开、旅行规划和中文天气预报；搜索与旅行卡片可点击真实搜索来源，天气使用阿里云百炼托管的高德地图 MCP（Amap Maps）。
- 聊天生图：平台判断器或 BYOK 原生工具决定生图，默认 Seedream 5.0 Flash；面板可选 Qwen Image 3.0（面板默认）或 Seedream 5.0 Flash，文字生成图片、参考图编辑、方形/横版/竖版、对话内预览与下载，生成图随会话保存。
- 写歌智能体：Claude 智能体模式下按创作简报、分段歌词与字数/押韵自检逐步确认，主人点卡片按钮生成试听；火山豆包音乐单供应商，P0 一次一版。
- 语音：浏览器录音、Qwen ASR、TTS HTTP/流式朗读；输入区只有一个语音按钮，轻点开始录音、再点一下发送，按住说话、松开发送。
- 社交连接：两层候选匹配、待接受卡片、双方接受后的真人房间和历史消息。
- 广场：热点、发帖、图片/短视频上传、点赞、兴趣与时间偏好；社群页面仍为占位。
- 多端：Next.js Web/PWA，以及加载开发隧道或公网网站的 Tauri 2 Windows 客户端。

## 技术栈

| 层 | 当前实现 |
|---|---|
| Web | Next.js 16.4.3、React 19、Tailwind CSS 4、React Three Fiber |
| API | FastAPI、Uvicorn、Pydantic、SlowAPI |
| 模型 | DashScope / Qwen（主力、轻量、视觉、搜索、生图、ASR、TTS）；生图和修图可选火山方舟 Seedream 5.0 Flash；写歌使用火山豆包音乐 v4.3（`VOLC_MUSIC_ACCESS_KEY` / `VOLC_MUSIC_SECRET_KEY`）；官方搭档可独立接入 DeepSeek V4 Pro |

| 桌面 | Tauri 2，Windows MSI/NSIS |
| 生产拓扑 | 单域名 Nginx，前端 `:3000`，后端 `127.0.0.1:8000` |

## 本地启动

### 1. 后端

项目当前开发环境使用 Python 3.14；依赖以 `backend/requirements*.txt` 为准。

```bash
cd backend
python -m venv .venv
```

macOS/Linux 激活环境：

```bash
source .venv/bin/activate
```

Windows PowerShell 激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装依赖并准备环境变量：

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env
```

在 `backend/.env` 中至少配置：

```dotenv
DASHSCOPE_API_KEY=...
JWT_SECRET=...
DEV_MODE=1
```

OpenAI 兼容模型客户端默认 60 秒超时、最多重试 1 次，可用 `DASHSCOPE_TIMEOUT_SECONDS` 和
`DASHSCOPE_MAX_RETRIES` 在模板允许范围内调整。搜索、旅行规划、热点展开和卡片详情
均使用 DashScope 原生 `qwen-plus` 接口并强制联网搜索，固定 30 秒 socket 超时、不重试，
不受这两个环境变量控制；卡片详情路由外层另有 45 秒总超时。
热点分类使用 `qwen3.8-flash`，请求固定 8 秒超时、不重试。危机复核使用独立异步客户端、不重试，
`FIONA_CRISIS_MODEL_ENABLED` 默认开启，仅 `0` 关闭；`FIONA_CRISIS_MODEL_TIMEOUT_SECONDS`
默认 `2.0` 秒，合法范围 `0.5–10`，无效值回落到默认值。
用户发图时的看图模型默认 `qwen3.8-omni-flash`（与主力对话同一模型），可用 `FIONA_CHAT_VISION_MODEL` 改为账号已开通的其他视觉模型；每次调用时读取，空值用默认，非法值回落默认并只告警一次，请求固定关闭思考模式。

天气需先在百炼控制台开通 Amap Maps，复用 `DASHSCOPE_API_KEY`；目前限时免费，结束后按量计费，单价以控制台为准。`FIONA_AMAP_ENABLED` 默认 `1`，只有字面 `0` 关闭；`FIONA_AMAP_TIMEOUT_SECONDS` 默认总预算 `8` 秒，合法范围 `1–30` 秒，空串、非数字、非有限值或越界值回落到 `8`。这些天气配置在调用时读取。

然后启动：

```bash
python run.py
```

API 默认监听 `http://127.0.0.1:8000`。数据库表会在应用启动时初始化。首次运行新版本会执行分身/会话版本迁移，为旧账号创建私有分身和默认会话，回填旧消息归属；更新已有部署前请按部署手册备份数据库与媒体。迁移失败会回滚该迁移并阻止启动。

### 2. 前端

前端字体为自托管思源宋体（`public/fonts/noto-serif-sc`，OFL）；外观可选跟随系统、昼、夜与素瓷。

Node.js 20+；锁文件已提交，优先使用 `npm ci`。

```bash
cd frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:3000`。`npm run dev` 默认只监听本机；开发环境通过 Next rewrite 将 `/api/*` 转发到本机 FastAPI，不需要额外配置前端 API 地址。确需局域网真机调试时，显式运行 `npm run dev:lan`，并按需设置 `FIONA_ALLOWED_DEV_ORIGINS`（逗号分隔；只填主机名或 IP，可用 `*.example.local` 这类通配，不带协议和端口）允许额外来源；这个模式会把开发前端暴露给局域网设备，可能让能访问它的人触及调试接口和内测数据，只在可信网络临时使用。

登录后从侧栏“分身”打开设置面板，也可直接访问 `/agents/me`，再回到聊天页创建或切换会话。名片默认私有；公开后只展示名称、头像和简介等安全字段。清空记忆会同时清除分身私有记忆和旧个人画像，聊天记录保留。

### Claude 智能体模式

Claude 智能体模式仅在 `FIONA_CLAUDE_AGENT` 开启、普通 `chat` 请求、危机级别为空、BYOK 已启用且 `provider == "anthropic"`、配置无错误且未触发 `byok_unreserved` 的余额守卫时进入。零余额用户保持原路由；high 和 possible 危机轮不进入智能体模式，生图/修图面板保持现状。`FIONA_CLAUDE_AGENT` 默认 `1`，每轮读取，只有字面 `0` 关闭，其他非法值按开启并只告警一次；关闭后 Claude 保留原生单轮生图路径。

Claude 自己决定天气、旅行、路线、热榜、生图工具，以及白名单轮次的写歌工具，可以把工具结果回灌后继续调用或作答；不走平台意图识别或生图判断器。本轮有图时直接 friend，不调用平台模式判定或视觉模型；无图时仍判定模式，镜子模式不带工具。本轮图片和工具结果发送给 Anthropic；联网搜索和网页读取由 Anthropic 执行，按其价格计入用户额度。提示前缀使用 ephemeral 缓存，本轮北京时间随 user 消息发送。

计费每轮仅预扣一次 10 颗草莓，不追加扣费：至少交付一张 `error=false` 且 `stale=false` 的平台工具卡，或生图成功，先累加计费项，整轮落库成功后才结算；后续工具失败不撤销已成立的计费。未落库的计费项退款，包括会话被删、保存失败或客户端断开；未保存的生成图会清理。否则全额退款。纯文字、Anthropic 联网搜索和 Claude 直接看图使用用户自己的 Key，不扣草莓；每日 `byok_chat` 在拿到首个全局槽后才计数，每轮仅计一次。

天气只匹配本轮用户原文或最近 3 条 user 消息原文，同时比较原文及其规范化结果。Claude 提供的城市可使用原样、规范化结果和去掉一个末尾行政后缀（市、省、区、县、州、盟、自治州、特别行政区）的写法，候选至少 2 个字，单字拒绝；实际查询使用匹配到的主人原文写法，再经 normalize_city 处理。北京/北京市、那曲市天气/那曲均可匹配。没有匹配就先询问城市，记忆、system、图片摘要和位置都不参与，也不在日志或 trace 记录城市/工具参数。

上限为每轮 4 次客户端工具、默认 240 秒整轮预算、可见文字累计 8000 字（单次仍限 4000 字）、每轮一张图。`FIONA_CLAUDE_AGENT_TOTAL_SECONDS` 默认 `240`，合法范围 `60–290` 秒，非法值回落默认；每次请求时限取剩余预算与现有 BYOK 时限的较小值。整轮保持每用户锁，Claude 请求期间才占全局槽，工具执行释放全局槽并发送心跳；重新获取槽最多等 10 秒。

本轮图片只处理发给 Claude 的副本：小图原样发送；长边超过 2000 像素或原始字节超过 3.5MB 时，在后台线程等比缩放到长边不超过 2000 像素。有透明通道的 PNG 保留 PNG，其他图片转 JPEG、质量 85；处理后仍超过 3.5MB 则继续缩小尺寸，media_type 与实际编码一致，上传落盘文件不变。

工具生图失败通过 image_failed 状态清除生成提示，失败原因回灌 Claude 后继续正常作答；工具来源的 done 不因缺图报错，面板生图及其重试行为保持原样。多步两段文字之间加两个换行，同样保存到正文。工具异常累加到 agent_tool_errors，成功保存的整轮仍执行画像提取等后续任务；模式判定、pending 或会话确认等平台侧失败沿用平台文案。尚未交付任何文字、平台卡片或图片就请求失败时，不补发来源卡，也不落库。全局槽等待超时显示「自带模型通道繁忙，请稍后再试」；预算耗尽时，完成的图片必须落库或清理，不能留下孤立文件。

已知局限：历史图片不再发送原图，仅发送「［图中：摘要］」文字；镜子模式不带工具；危机轮不进入智能体模式；卡片不落库，刷新后仅保留正文摘要和生成图；写歌卡例外，消息新增可空 `song_project_id`，刷新后按它重建。进入智能体路径即清除 pending，不读写工具补参；本轮只保存一条 assistant，按文字、卡片摘要和生图描述的交付顺序拼接。服务器端工具版本、结果块类型和 `usage.server_tool_use` 字段仍需作者用真实 Key 核实。

### 写歌智能体（P0）

在聊天里说「帮我写首歌」即可进入。写歌只在 Claude 智能体模式、`FIONA_SONG_AGENT=1` 且用户名精确列入 `FIONA_SONG_USERS` 时开放；默认关闭，空白名单无人可用，危机轮不开放。写歌开启的轮次会把固定写歌模式提示词拼进系统提示（`_final_system_prompt` 的入参），基础安全规则仍在最后一条 system 消息末尾且恰好出现一次，并在本轮 user 消息里带上本会话最近一个写歌项目的摘要；`CLAUDE_CLIENT_TOOLS` 仍是原来的 5 个，四个写歌工具只在白名单轮次按请求追加，写歌关闭时请求、提示词与消息逐字节不变。

1. Claude 先简短了解写给谁、什么场合、想要的情绪与曲风、大约多长，一次最多问三个问题。
2. 用 `song_save_brief` 保存创作简报和结构蓝图：段落、每段行数、每行字数范围与押韵格式。
3. 用 `song_save_lyrics` 提交整首歌词；服务端用纯代码检查结构、字数与十三辙押韵，有「问题」先自行修改再提交，只有「提醒」时说明取舍。
4. 主人在卡片上看到简报、按段歌词、每行字数与押韵标记、自检结果；点某段「改这一段」后，Claude 用 `song_revise_section` 只改那一段，其他段逐字保留。
5. 主人点「生成试听（N 草莓）」并在确认框确认后，才会预扣草莓并提交火山生成；模型不能替主人触发。
6. 火山异步生成，卡片显示排队、进度和保存状态，完成后可播放、下载；`song_get_status` 供 Claude 读取简报、歌词、自检和最近版本。
7. 音频写入 AI 隐式标识，卡片页眉在所有状态下都显示「AI 生成」。

计费：每次生成预扣 `FIONA_SONG_STRAWBERRIES`（默认 30，1–500）颗，失败、不确定、超时或 `rejected` 自动退回且只退一次，`DEV_MODE=1` 不扣不退；同幂等键重复提交只扣一次。每日 `FIONA_DAILY_SONGS` 默认 10（1–100，上海自然日，`DEV_MODE` 不豁免），每用户同时最多 `FIONA_SONG_MAX_INFLIGHT` 个在途生成（默认 2，1–5）。

供应商与隐私：P0 只接火山豆包音乐 v4.3，使用 `GenSongForTime` 提交、`QuerySong` 查询，每次 1 版；`Captions` 原样保存、不解析；不做腾讯 MPS/MiniMax，也不做两版对比。写歌时歌词与曲风参数会发送给字节跳动火山引擎；Claude 侧仍是用户自带 Key。火山子账号 AK/SK 只从 `VOLC_MUSIC_ACCESS_KEY`、`VOLC_MUSIC_SECRET_KEY` 读取，缺一即生成接口返回 409「写歌服务未配置」，不写数据库、日志、trace、异常文案或响应。

标识与数据：音频写 ID3v2.4 `TXXX:AIGC` 隐式标识（`ContentProducer`/`ProduceID`），界面常驻「AI 生成」；`FIONA_SONG_EXPLICIT_WATERMARK` 默认 `1`，只有字面 `0` 关闭（火山显式水印），`FIONA_AIGC_PRODUCER` 默认 `Fiona`。音频根目录 `FIONA_SONG_DIR` 默认 `backend/song_data/`，生产使用 `/var/lib/fiona/songs`；不放进 `uploads/`、不挂静态目录，经 `/songs/versions/{id}/audio` 鉴权并按 Range 返回。SQLite 新增 `song_projects`、`song_lyrics`、`song_versions`、`song_cleanup_queue` 四表，`init_db` 幂等建表，`messages` 补可空 `song_project_id`；不增加迁移版本，`/health` 仍只校验五道迁移。

删除：删号、删会话和清空历史会在各自原有事务内删除对应的写歌项目、歌词和版本行，把音频路径登记进 `song_cleanup_queue`，提交后再清理；只删 `FIONA_SONG_DIR` 根内的普通文件，拒绝符号链接与 `..`。启动时仅在开关打开时做孤儿清扫并启动轮询器。刷新后写歌卡按 `messages.song_project_id` 重建；同一项目出现在多条消息里时，只有最新一条显示完整卡片。

已知局限：火山没有局部编辑，改一段词只能整首重新生成，旋律不保证延续；`Captions` 未解析；只对 Claude 智能体模式开放；P0 只接火山、一次一版；备份脚本尚未包含写歌目录（P2）。

### 聊天生图：判断器与原生工具

以下判断器/原生单轮生图说明适用于智能体模式之外的路由；Claude 启用智能体模式时按上节的多步工具流程执行。

`FIONA_CHAT_IMAGE_TOOL` 默认 `1`，只有字面 `0` 关闭，每次调用时读取；其他非法值按开启处理并只告警一次。仅普通 chat、无本轮图片、非 high/possible 危机、未触发零余额守卫且 BYOK 配置正常时启用新生图流程，不再按回复模型白名单排除。关闭开关或判断器不可用时退回旧路由，仍跟随面板选择。危机轮不经新路径生图；possible 信息/求助语境的生图 pending 沿用旧路由，可能清除；非信息语境的 possible 轮保留生图 pending。

两种模式：**原生工具模式 native** 仅用于关闭智能体模式的 BYOK Claude 三个型号及 DeepSeek 精确型号 `deepseek-v4-pro` / `deepseek-flash`，由用户模型根据完整对话调用 `generate_image`。**判断器模式 planner** 用于平台主力/轻量槽、BYOK DashScope（所有型号）、Moonshot/Kimi、智谱、自定义地址及 DeepSeek 其他型号。Kimi、智谱、自定义地址改走判断器模式，回复模型不下发任何工具；平台 `stream_normal` 恢复原 700 token 文字回复。

判断器使用平台轻量模型 `qwen3.8-flash`：本轮预筛命中画图/图片/风格/提示词/模型名等线索或现有显式生图候选、上一条回复与生图相关，或存在待补充的生图请求时，这一轮会多一次约 1–5 秒的判断器调用。已有生图 pending 的取消短语不调用判断器，沿用原取消逻辑。判断器读取最近 6 条对话（含本轮原话，历史每条最多 600 字，本轮原话最多 1500 字（超长时保留首尾）），以「主人：」「你：」前缀按时间排列，发送给阿里云 DashScope；历史 assistant 的「使用的描述」行保留。不传人设或私有记忆。非流式 JSON、关闭思考、600 tokens、在线程执行、8 秒总超时，不重试；超时、异常、非 JSON、非法 draw 或要画时描述为空/超长均判为不可用。判断器不可用时退回旧路由；日志和 trace 不写对话或描述。

判断器判为要画时先清除所有 pending，再直接执行生图，不调用回复模型、意图识别或模式判定，也不消耗 `byok_chat` 次数、不发回复模型标签；判断器模式下镜子模式也能生图。判为不画或未满足判断器调用条件时跳过自然语言生图候选，不新建生图 pending，已有生图 pending 除取消外清除后继续；天气 pending、镜子与其他工具仍按原逻辑，意图识别的 `generate_image` 视为无意图。原生模式候选确认后绕过镜子进入带工具的 friend 回复，非候选镜子回复不下发工具。

两种模式每轮最多一张图，执行后直接结束，不把结果回灌给回复模型；完成文字及「使用的描述」行合在一条 assistant 正文落库，原生模式保留前导文字，判断器模式没有前导文字，刷新及下一轮仍可见。描述行不进入朗读缓冲。新路径忽略面板 `image_model`，默认 Seedream 5.0 Flash；点名千问/通义/Qwen 用 Qwen Image 3.0。选中模型未配置而另一个可用时，发请求前降级并说明；已发请求失败不跨供应商重试。面板生图/修图完全不变，默认 Qwen、按用户选择。成功扣 10 颗、失败退款，BYOK 文字仍免费，每轮不重复预扣。

隐私：判断器读取的最近对话发给阿里云 DashScope；原生模式由用户自选的 Claude 或上述 DeepSeek 型号决定何时生图、撰写描述。两种模式默认把根据对话撰写的描述发送给字节跳动火山引擎，描述可能包含对话里出现过的内容；描述不得含账号名、真实姓名、私有记忆里的个人细节。图片仍由平台执行并扣草莓；Qwen 描述发送给阿里云 DashScope，面板路径只发送本轮描述和所选参考图。

时限：Nginx `proxy_read_timeout` 按两次读之间的间隔计算，BYOK 等待和生图期间每 10 秒有一次心跳。原生模式最坏耗时为 BYOK 首轮（默认 120 秒或高档 180 秒）加生图 150 秒；生图在 BYOK 流关闭并释放并发槽后执行，不计入 BYOK 总时限。判断器模式先最多 8 秒判断，再执行最多 150 秒生图；判为不画才调用回复模型。

已知局限：原生模式下镜子非候选句不出图，其他工具意图仍优先；判断器模式由判断器先裁决，判为不画才进入天气、搜索等意图路由。Qwen 的 `prompt_extend` 会改写描述，显示描述不等于最终渲染所用描述；「改成动漫风」是重新生成新图，不保留原图构图，修改已有图应点「以此图修改」；已配置 Key 但 Seedream 未开通时，每次都会失败并提示「用千问画」。

### 自带聊天模型（BYOK）

在设置页「聊天模型」中选择通义、DeepSeek、Kimi、智谱、Claude 或自定义 OpenAI 兼容地址，填写模型名和 Key，可先测试再保存。Claude 只允许 `claude-opus-5-5`（默认）、`claude-sonnet-5-5`、`claude-haiku-5-5`；自定义地址仅允许公网 HTTPS，服务端校验 DNS 并固定到公网 IP、不跟随重定向。输入区可切回平台，BYOK 气泡标注「由你的模型回复」，该标注刷新后消失。普通/镜子聊天回复走用户模型；智能体模式关闭时的 Claude 与两个精确 DeepSeek 型号的原生模式由用户模型决定生图，其余使用平台判断器，图片由平台执行；分身交流和官方创作搭档全部仍用平台。自定义上游响应上限 4 MiB。custom 强制请求头 Accept-Encoding: identity，拒绝非空且非 identity 的 Content-Encoding，避免解压绕过 4 MiB 上限；错误仍归「连不上该服务」。响应头到达后，所有厂商在总时限或取消时立即中断；上游在返回响应头之前挂起时，预设厂商最多再等 60 秒读超时，custom 在 TLS 建立后立即中断；DNS 解析与 TCP/TLS 建连阶段分别最多等约 5 秒和 60 秒连接超时。中断线程只标记状态并 shutdown socket，阻塞调用返回后由属主 worker 关闭流、客户端和连接池。测试连接的平台限流为 10 次/分钟，命中时仍以 HTTP 200 返回 ok:false 和「操作太频繁，请稍后再试」。Claude 过载显示固定「服务繁忙，请稍后再试」。

Claude 思考强度可选低 / 中 / 高，默认低。保存 Claude 配置后，可在聊天输入底栏或设置页立即切换并保存到账号，换设备也生效；调高后会先思考再回答，更慢，用户自己的额度消耗也随档位上升。其他厂商不受影响。

| 思考强度 | `max_tokens` 普通/镜子 | 单条总时限 |
| --- | --- | --- |
| 低（`low`） | 4096/2048 | `FIONA_BYOK_TOTAL_SECONDS`，默认 120 秒 |
| 中（`medium`） | 8192/4096 | `FIONA_BYOK_TOTAL_SECONDS`，默认 120 秒 |
| 高（`high`） | 16384/8192 | `min(240, FIONA_BYOK_TOTAL_SECONDS×1.5)`，默认 180 秒 |

`max_tokens` 同时限制思考与正文；单次请求正文仍限普通 4000 字、镜子 600 字，智能体整轮累计限 8000 字。Nginx 的 300 秒是两次读之间的间隔，并非整轮总时限；测试连接固定低档、1024 tokens 和原总时限。`user_model_configs` 新增 `effort TEXT NOT NULL DEFAULT 'low'`，老库启动时自动补列，已有行默认低；不增加迁移版本号，该 BYOK 变更不增加健康检查项。保存模型、Key 或切换厂商保留原档位，只在 Claude 下生效。

启用后，每条聊天回复会把分身设定、用户的私有长期记忆、本会话最近 60 条消息（含平台看图生成的图片描述）与本条消息发送给用户选择的厂商；系统提示中的账号名替换为「（账号已隐藏）」。危机复核、工具执行、图片执行及朗读仍由平台处理并读取对话内容；智能体模式之外的意图识别、模式判定和看图也由平台处理；原生模式由关闭智能体模式的 Claude 或两个精确 DeepSeek 型号决定生图，其他 BYOK 使用平台判断器读取最近 6 条对话（历史每条最多 600 字，本轮原话最多 1500 字（超长时保留首尾）），画像提取也仍由平台执行，并会读到用户模型的回复；明确危机轮仍由平台回复。用户模型失败不改用平台模型。Key 加密保存，删除 Key 或删号时删除，数据库备份中最多保留 14 天，无服务端密钥无法解密。长期归档副本须先清除 Key 密文，步骤见部署手册。Claude 的接口不对中国大陆提供服务，大陆服务器通常无法连接该预设。

有余额时照常先预扣，BYOK 纯文字回复结束后退还 10 颗草莓，工具生图成功时结算这次预扣；余额 0 或不足 10 颗时，启用 BYOK 的用户仍可聊天，但工具、看图、生图与修图返回原草莓不足文案。high 轮余额不足时免费送资源、不调用回复模型、不落库；平台聊天回复、成功工具、看图与生图仍照常结算。每日 BYOK 聊天默认 200 次、测试连接默认 20 次。

零余额且已启用 BYOK、未预扣时，generate_image / weather 以外的 pending：「算了/取消/不用了/不要了/不查了/没事了」免费取消并清 pending；以「先聊/聊点/换个话题/先不」开头清 pending、由用户模型回复；其他补参消息仍报草莓不足、pending 保留。天气 pending 的「换个话题」类句子同样清 pending、由用户模型回复；余额充足用户与平台路由保持不变。

服务端 `FIONA_BYOK_SECRET` 为 url-safe base64 编码的 32 字节，单独保管，不进入数据库/媒体备份；丢失时用户重新填写自己的 Key 即可。`FIONA_BYOK_SECRET_PREVIOUS` 为逗号分隔的旧密钥，仅用于解密，用户下次保存使用当前密钥重新加密。缺失或非法密钥、十一项污染客户端的环境变量会使 BYOK 不可用（含 `ANTHROPIC_CUSTOM_HEADERS`，完整清单见部署手册），DEV_MODE 也没有固定回退值。预设厂商（含 Claude）遵循服务器的 HTTP(S)_PROXY / NO_PROXY 出站代理设置；自定义地址不使用环境代理。 `FIONA_BYOK_MAX_STREAMS` 默认 8（1–64），全进程使用专用有界线程池，每用户同时一条；`FIONA_BYOK_TOTAL_SECONDS` 默认 120（10–240）秒，两项调用时读取，非法值回退并只告警一次。生成服务端密钥：

```bash
python -c "import secrets,base64;print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
```

搜索与旅行卡片在要点下方显示最多 5 条可点击来源（标题和站点），通过现有安全外链入口打开。来源只取自 DashScope 原生响应的 `output.search_info.search_results`，经公网 HTTP(S) 格式校验后附加，模型生成的 URL 不进入卡片；行程标题、要点与非 JSON 回退文本会清理引用角标及模型写入的 HTTP(S)、www. 和 Markdown 链接，朗读和聊天文字摘要使用清理后的正文。没有可核实来源的搜索返回错误且不计费；旅行建议允许没有来源。卡片及来源目前不落库，刷新或切换会话后只保留文字摘要，来源不会恢复。

“明天杭州会下雨吗”“杭州冷不冷”“要带伞吗”走独立的 `weather` 意图；没明确城市时追问“哪个城市？”，回复“算了”可取消，明显不是城市的回复按新消息处理。天气卡最多展示四天的中文白天/夜间天况、最高最低温和风向风力，成功交付才按普通工具扣草莓，失败、取消、缺参追问和超限均不扣草莓；天气卡结构目前不落库，只保存文字摘要。隐私数据流：每次只把用户本轮或最近对话里明确说出的城市名发送给阿里云百炼托管的高德地图服务，不发送聊天历史、私有记忆或用户位置，不做 IP 定位，不猜测或默认城市。包含“天气”的普通 `web_search` 查询仍走原生联网搜索。

意图识别出口对白名单 `web_search`、`hot_topics`、`route`、`travel_plan`、`get_datetime`、`fetch_card`、`generate_image`、`weather` 及各自参数、缺失字段做格式规范化，未知或畸形意图回落为空意图。

在聊天输入区的「图片」菜单里选“生成图片”，选择 `1:1`、`16:9` 或 `9:16` 后填写画面描述；也可以直接发送“帮我生成一张薄雾古庙图片”。每次生成一张，可在气泡中放大和下载，刷新会话仍可查看。生图和修图都可选 Qwen Image 3.0（默认）或 Seedream 5.0 Flash；选择会保存在本机，切换账号或会话后保留，开关关闭或判断器不可用时，普通聊天里的自然语言生图跟随该选择；工具路径忽略该选择、默认 Seedream，失败不显示面板重新生成按钮；面板失败重试使用当前界面选中的模型。Qwen 使用已有 `DASHSCOPE_API_KEY`，可通过 `QWEN_IMAGE_MODEL` 配置；Seedream 使用火山方舟 `ARK_API_KEY` 和 `SEEDREAM_IMAGE_MODEL`（默认 `doubao-seedream-5-0-flash-260915`），须先在方舟控制台开通模型。成功获取模型列表后，未配置密钥的模型按钮不可选，已选不可用项暂时回到默认模型，保留本机偏好，之后获取到该模型可用时恢复原选择；列表请求失败时两项均可选，由服务端报错。图片请求发出后失败时不会自动更换供应商；工具路径仅在发请求前可因未配置 Key 降级。选择 Qwen 时描述和参考图发送给阿里云 DashScope；选择 Seedream 时发送给字节跳动火山引擎。两个模型每次都扣 10 颗草莓，失败照常退款；单次生成和下载总超时 150 秒，不自动重试，失败可手动重试。生成图仅会话所属用户可访问，删除消息或会话时清理已无引用的文件。

需要调整已有图片时，点击该图的“以此图修改”，还可在其他图上点“加入参考”，或在输入区「图片」菜单里选“改一张图”从电脑选择图片。本地图片和当前对话生成图可以混用，合计最多 3 张；本地支持 PNG、JPEG、WebP，每张不超过 5MB。输入区按选择顺序显示图1、图2、图3，可以移除或调整顺序，再输入例如“用图1的人物、图2的场景、图3的色调”。本地图片会纠正方向、移除元数据并适配模型尺寸，发送修改指令时才上传；比例超过 4:1 的图片需先裁剪。默认沿用处理后图1的尺寸；Seedream 在目标尺寸不足或超过限制时按比例缩放，缩放后的宽高取 8 的倍数；比例误差不超过 1% 的候选中优先选择最接近目标面积的尺寸。两个供应商读取本地参考 PNG 时都使用 2048² 像素上限。每次修改产生一张新图；全部参考图、顺序和修改要求都保存在对话里，新图也能继续作为参考。取消参考或切换会话会退出编辑，失败重试仍使用原先那组图与顺序。普通聊天的图片附件仍用于看图聊天。

侧栏“分身广场”或 `/agents` 可浏览其他公开分身。双方先公开名片，发起方填写主题与回复次数，对方在“收到的邀请”中接受后开始交流。双方合计最多 6 次回复，随后生成一次总结；任何一方可以立即停止。交流仅使用公开名片与当前交流内容，不读取人格设定、私聊或私有记忆。记录仅双方可见；关闭公开名片会停止待处理与进行中的交流。所有交流模型调用都带基础安全规则。内测阶段会消耗平台模型用量，不扣草莓，也不执行外部工具。

一个人也可在广场默认的“单人体验”中选择“创意搭档”“脚本编辑”或“短视频创意搭档”。它们是平台官方 AI，没有真人主人，也不占用用户账号。填写主题并点击“开始讨论”后，进入“主创初稿 → 官方审稿 → 主创修订”的作品协作。你的分身提交完整稿件，官方搭档核对原始要求并列出修订意见。默认双方合计最多 99 次，可填写 2–99 的整数；审稿通过即提前结束，直接保留通过审稿的完整版本，在“体验记录”查看。无需公开自己的名片或注册第二个账号；仅使用自己的分身名称、简介与本次讨论，不读取人格设定、私聊或私有记忆，记录仅本人可见。内测不扣草莓；生产限流开启时，每账号每天北京时间自然日默认可创建 3 次体验，由 `FIONA_DAILY_OFFICIAL_EXCHANGES` 配置，停止或失败也计入。关闭名片公开不会停止官方体验，可用“停止交流”结束。

聊天与工具的八项每日上限为官方体验 3、热点展开 30、卡片详情 30、ASR 300、天气 30、自带模型聊天 200、测试连接 20、成功读小说 60（`FIONA_DAILY_NOVEL_READS`）；自带模型两项分别由 `FIONA_DAILY_BYOK_CHATS`（`byok_chat`）、`FIONA_DAILY_BYOK_TESTS`（`byok_test`）配置。配置均调用时读取，只接受正整数，非法值回落默认并只告警一次；开发模式或关闭限流器时跳过。官方创建用数据库事务计数，热点展开、卡片详情、ASR、天气分别沿用 `FIONA_DAILY_HOT_EXPANDS`、`FIONA_DAILY_CARD_DETAILS`、`FIONA_DAILY_ASR`、`FIONA_DAILY_WEATHER`；其余七项使用单进程内存计数，重启清零、北京零点换日；读小说仅成功读取计数，其余上游失败不退还次数。BYOK 聊天先检查并发，再计每日次数；超限在流内报错、退款，测试连接超限仍用 HTTP 200 返回 `ok:false`。 天气缺参追问只检查额度，取消和本地校验失败不计数；天气超限返回聊天错误事件，不写 pending、不扣草莓，成功天气卡才按普通工具结算。官方体验、热点展开、卡片详情及 ASR 四类 HTTP 超限仍返回 429 和 `Retry-After`；语音识别超限会关闭免提，可先打字。

“短视频创意搭档”专门从零发展短片创意：人物冲突、前三秒钩子、剧情反转，逐步细化成分镜、台词、音效和时长安排。结束时按讨论结果整理带时间段的剧本；遵循话题指定的时长，未指定时以 30–60 秒为起点。它负责剧本讨论，不直接生成视频。

单人体验的话题支持最多 10,000 字，可填写人物设定、剧情背景、风格与时长要求，后端完整保存并提供给每次写稿和审稿；最新完整作品和最近审稿意见也会完整保留在模型上下文中。长话题在详情中默认显示预览，可展开阅读、滚动或复制全文。与其他用户分身的邀请主题仍最多 300 字。

新创作的详情顶部展示“当前作品”，可下载作品 Markdown、`README.md`（完整稿件、原始需求和审核状态）以及完整讨论 Markdown（全部写稿、审稿和修订过程）。审稿通过标为“AI 审稿通过 · 待你验收”；达到次数上限、重复无进展、输出不完整或手动停止时保留草稿。历史讨论继续提供原有 README 与完整讨论导出，无需重新调用模型。下载权限与查看交流一致。

官方搭档支持独立模型：在后端 `.env` 配置 `OFFICIAL_EXCHANGE_PROVIDER=deepseek`、`OFFICIAL_EXCHANGE_MODEL=deepseek-v4-pro` 和 `DEEPSEEK_API_KEY` 后重启后端，官方审稿及历史流程的体验总结使用 DeepSeek V4 Pro，自己的分身继续使用 Qwen 主模型。未配置时官方搭档也使用 DashScope。模型名称显示在官方名片中，密钥仅留在后端；不会在供应商失败时暗中回退到另一个模型。DeepSeek 使用[官方接口](https://api-docs.deepseek.com/quick_start/)。

Windows 也可以在根目录运行 `start.ps1`，它会分别打开后端和前端进程。

## 登录与本地调试

- 内测登录使用邀请码：`POST /auth/redeem-invite`。
- 浏览器登录成功后使用服务端签发的 `HttpOnly` Cookie；退出登录会撤销该账号此前签发的会话。
- `backend/seed_invites.py` 用于创建绑定新 `testerNN` 用户名的邀请码，编号不会与现有账号、邀请码绑定名或已退役用户名重复，删号后不回收；新账号使用随机的初始会话版本，旧账号版本不变。`backend/manage_invites.py` 用于查看、撤销和轮换邀请码。
- 生产私聊能扣就先原子预扣 10 颗草莓，只对已保存的平台模型回复、已生成并保存的图片或成功真实工具结算；BYOK 聊天回复不扣草莓、退还预扣。零余额启用 BYOK 时只允许用户模型聊天，工具、生图、看图保持草莓不足。失败、缺参追问和桌面占位工具退还预扣。`STRAWBERRY_DAILY_REFILL` 可配置每日补到至少指定余额（默认 `0` 为关闭），管理员可用 `backend/manage_strawberries.py` 手动补充。
- 私聊危机采用规则加模型复核：规则 `high` 直接进入支持流程；其他非空文字消息由 `qwen3.8-flash` 复核，只看当前消息；超过 2000 字时取首尾各 1000 字，中间用「……」连接。取较高档位，不能降档。复核与预扣、上下文装配并行，默认 2 秒超时，失败按规则结果走；只记录档位、异常类型和耗时，不记录原文。信息或求助语境只看规则，模型从未命中升到可能相关时跳过工具。明确的第一人称自伤或自杀危机进入支持流程，不执行工具或普通镜子话术；余额足够时按正常轮次预扣和结算，不足时无需付费即可收到资源文案且不调用回复模型。可能相关的表达保留模式判定、镜子、看图、普通回复与计费；除信息或求助语境外，跳过自然语言生图候选、意图识别、工具及待补参数，保留 pending。信息或求助语境、界面显式生图或修图、缺少修图参考的固定引导保持原路由；唯一例外是已有天气 pending 时，到达工具路由的 `possible` 信息或求助语句清除该 pending，按新消息路由，不能当作城市名发给高德。文字、工具、图片及失败路径都会附求助资源，余额不足时免费先送资源再提示余额。进入 `/chat` 路由之前发生的 422 请求校验和 429 限流不在资源送达保证范围内。模型不能消除规则已有的日常误判。繁体『計畫』与『計劃』判级一致。图片模式中的明确危机按文字回复显示。普通私聊和分身交流的模型提示词均带基础安全规则。
- `DEV_MODE=1` 时仅对回环地址开放 `/auth/test-login` 和 `X-Dev-User` 等调试通道；工作室还须显式设置 `FIONA_STUDIO_REQUIRE_JWT=0` 才接受开发身份；不要经不可信代理转发开发站点。
- 生产环境必须使用 `DEV_MODE=0` 和足够强的 `JWT_SECRET`。

## 本机监控（macOS）

在设置页「本机监控」生成设备令牌、选择最近发现的窗口并建立关键词、数值或 AI 规则，再运行 [Mac 监控程序](watcher-mac/README.md)。数据流为：本机 OCR → 只上报新增行 → 服务端判断 → 写进聊天。截图、整页文字和前三次 OCR 快照保留在 Mac 内存；新增文字只用于判断，不落日志、不写 trace，数据库只保存提醒摘要和聊天里的提醒正文。关键词和数值在后端本地判断；AI 默认把新增文字发给阿里云千问，选择 Claude 时发给用户已启用的 Anthropic BYOK，不可用时不回退。

`FIONA_LOCAL_WATCH` 默认 `1`，设为 `0` 后所有 `/local-watch/*` 接口返回 404。`FIONA_DAILY_WATCH_JUDGE` 默认 `500`，限制每账号每天 AI 判断次数，即使开发模式或通用限流关闭也生效；提醒不扣草莓。设备令牌只显示一次，后端仅存 SHA-256 哈希；令牌等同访问凭据，不提交仓库、不放进命令行参数。复制后使用 `mkdir -p ~/.fiona && umask 077 && pbpaste > ~/.fiona/watcher.token` 写入文件，确认权限为 `600`；已有文件需另行 `chmod 600 ~/.fiona/watcher.token`。泄露或不再使用时在设置页吊销，最多 3 台有效设备、20 条规则。

已知局限：只支持 macOS（14 及以上）；窗口最小化后截不到；OCR 可能有错字；只能看到窗口当前显示的内容。Fiona 页面关闭时不会实时弹出，但提醒照样落库。浏览器通知需用户在设置中主动允许；监控只被动读取屏幕，不操作窗口。

屏幕锁定或显示器休眠时 macOS 不允许截取窗口，期间无法监控。如果需要离开电脑时也能监控，可以在 系统设置 → 锁定屏幕 中延长自动锁定时间，但要自行权衡安全。设置页逐条显示监控状态；截图失败会记录不含窗口文字的日志并通过心跳上报，超过 5 分钟未收到状态会显示「监控程序未在运行」。

### 小说工坊（书斋内测）

小说工坊复用 `backend/novel/` 的 P0 推演、写作、审校与归档引擎，以 SQLite 存储步骤并在后台按章运行。`/novels` 提供 catalog、estimate、建书/列表/详情、章节、立项与细纲确认、重定稿、继续/暂停/恢复、预算修改、留言、改稿、完结确认/拒绝、Markdown 导出和删除；全部要求登录。`FIONA_NOVEL=1` 且用户名列入 `FIONA_NOVEL_USERS` 才可访问，默认关闭，空白名单无人可用。

推演结构 v2 第一期通过后端请求显式传 `structure: "v2"` 开启，默认仍为 v1，界面保持现状。v2 会提炼类型承诺、每十章先开卷会议，并检查爽点节奏、核心主线、里程碑和伏笔预算。卷规划默认自动批准；后台可设 `volume_gate=true` 测试卷确认接口，建书请求暂不开放此配置。`GET /novels/{id}/volumes` 查看卷规划和里程碑，`POST /novels/{id}/volume/approve`、`volume/redo` 批准或付费重做；`upgrade-structure` 可在暂停或批次审阅时付费升级旧书，不重写旧章节、不打开卷关卡。所有 P1 书的审校复审限制在上一轮问题及本轮改动范围，避免不断追加未改段落的新阻断。

新增表为 `novels`、`novel_bible_versions`、`novel_chapters`、`novel_steps`、`novel_notes`，初始化使用幂等建表，不增加迁移版本；删书和删号清理全部关联数据。全局并发 `FIONA_NOVEL_MAX_RUNNING=3`，每日章节 `FIONA_DAILY_NOVEL_CHAPTERS=30`；`FIONA_NOVEL_PRICE_JSON` 可整体覆盖价目。平台模型为千问、DeepSeek、豆包；Claude 只能使用用户已启用的 BYOK。平台按实际 token 预扣/结算草莓，BYOK、fake、DEV_MODE 免费。

前端从侧栏第六个书签「书斋」进入：`/novels` 是书架，`/novels/new` 是三步建书向导，`/novels/[id]` 是目录、正文与推演/圣经/留言工作台。主页以常驻 iframe `/novels?embed=1` 承载，内页保留嵌入参数，也可在新页面打开。立项、细纲、审阅和完结关卡支持作者确认，后台运行期间仅在页面可见时每 3 秒刷新；完整圣经和留言分别由只读 `GET /novels/{id}/bible`、`GET /novels/{id}/notes` 提供。

建书时可选「这本书要改编成短剧」，默认不勾选，建书后不能修改。勾选后会尝试加入短剧改编顾问，并让审校对场景数、主要人物数超限的硬伤要求重写，每章可能增加草莓支出；顾问仍可手动取消。P1 档案员新增人物必须补足至少 20 字外形。圣经人物卡会提示外形不足，并在等你审阅、等你确认细纲、等你确认完结、已暂停或已完结时提供修改表单；`PATCH /novels/{id}/characters/{character_id}` 仅修改外形、性格、动机，保存为新的圣经版本。

Markdown 导出保留所有有正文的章节；前文改稿后标为 stale 的章节会在标题下显示「待复核」，书首汇总章号，没有待复核章节时输出保持原样。短片工作室可在进程内调用只读服务 `find_books(username, query)` 按书名查找本人的书，或 `chapters_range(username, novel_id, start, end)` 读取 1–300 章范围内至多 50 章；这两项不提供新 HTTP 路由。

隐私：故事思路、圣经、正文与留言会发给所选厂商，可能包括阿里云百炼、DeepSeek、火山方舟以及自带模型厂商 Anthropic。小说步骤不存提示词，只存请求摘要、模型产物与用量；密钥不进入小说表、日志或接口。失败重试照常计费；真实厂商质量与可达性需作者另行验收。

## 短片工作室（WO1–WO3e）

作者可访问 `/studio` 新建项目，再在默认「④镜头」页上传首帧、填写提示词并选择模型、分辨率、时长和音频。先查看报价和今日额度，再点击「确认生成（最多 ¥x.xx）」。镜头墙显示中文状态、花费和成片；不确定的任务需核对控制台，可关联任务号或二次确认未扣费后释放额度。「用同样参数重新报价」只回填，不会自动报价或提交。「①拆解」已开放拆解与分集，「②定妆」开放到 G1 定妆与声线，③④将在后续版本开放。

新建项目可选择空白项目、小说工坊、上传 txt/md/docx、粘贴文本或「短视频创意搭档」的已完成成稿。小说工坊仅显示本人作品，已完结且圣经齐全、各章完成、没有待复核或正在改稿的书才能导入；「改编短剧」作品优先显示，审校 flags 仅作提示。小说单本页的页头及完结横幅也提供「做成片」，仅工作室作者可见；已有项目可直接打开，也能再建一个。正文上限 50 万字，上传上限 10 MB。

导入会在工作室本地建立快照，保留正文、圣经、罗盘、精简细纲和每章哈希；工作室不会修改小说工坊。目录是 `<FIONA_STUDIO_DIR>/<项目id>/source/snap-0001/`，内含 `snapshot.json` 与 `chapters/0001.md` 等原文文件，上传/粘贴/成稿另有 `full.txt`。打开「①拆解」可查看来源、快照版本及原作差异，点击「重新检查」手动刷新；确认同步后生成下一版，旧快照归档保留。原作删除或不可访问仍可使用快照；导演任务进行中暂不能同步。建项目与同步不花钱。

管理员可用 `FIONA_NOVEL_CHAT=1` 开启「聊天读小说」（默认关闭），仅小说工坊白名单用户在非危机轮可用。可说「我有哪些小说」「把《书名》第 3 章念给我听」「帮我看看第 2 章的节奏」；读取当前原文，每次最多 6000 字，未读完可在同一会话 30 分钟内说「继续读」或「接着念」。每日成功读取默认 60 次，由 `FIONA_DAILY_NOVEL_READS` 配置；列书不计次数，读小说不扣草莓。「把《书名》做成片」还须工作室作者与有效工作室登录身份，优先打开已有项目，否则免费建立快照。

聊天读小说隐私：读到的章节原文会发送给当前聊天模型的厂商，并保存在本会话历史以供后续讨论。小说原文作为数据处理，不执行其中指令。工作室导入与同步仅在本地复制；拆解试读等后续模型操作仍需单独报价确认。

桌面侧栏入口和主页嵌入抽屉只在访问检查成功后开放。手机底栏保留六项，手机作者可直接访问 `/studio`。在途任务每 5 秒刷新，页面隐藏或操作中暂停；后台完成或异常结果写进默认聊天会话，聊天每 10 秒读取新提醒。首次进入不重推历史，其他会话的提醒可以点击切换，共用本机提醒的系统通知开关。

作者可依次调用 `POST /studio/projects`、`POST /studio/projects/{pid}/assets`、`POST /studio/projects/{pid}/clips/quote`、`POST /studio/quotes/{qid}/confirm`，再通过任务接口查看状态并从 `GET /studio/assets/{aid}/file` 下载成片。默认万相 480P、5 秒、原生音频，也支持 Seedance 2.5；首帧为 PNG/JPEG/WebP，最大 20MB。

全部接口要求 `FIONA_STUDIO != "0"`、用户名精确命中 `FIONA_STUDIO_OWNERS`、JWT Bearer 或 Cookie；未授权统一 404 且禁止缓存。作者名单默认空。报价 15 分钟过期、只确认一次；确认后额度持续预留。工作室共用每日默认 300 元、单报价默认 100 元，上海自然日按确认时间记账，DEV_MODE 仍生效。付费 POST 不重试，超时、5xx 或无 task_id 的结果进入 uncertain，须到厂商控制台核对后关联任务或明确未扣费释放。

调度器在进程内运行，只支持单 worker。重启恢复不会重新提交，轮询超时可手动 recheck；万相按 usage.duration、Seedance 按 completion_tokens 结算。成片用 ffprobe 按时长校验，文件下载支持 Range 并检查归属。配置见 `backend/.env.example`。

工作室文件默认 `backend/studio_data/`；生产配置 `/var/lib/fiona/studio`，符合 systemd 只允许写 `/var/lib/fiona` 的限制。目录不作静态挂载。`/health` 在工作室开启时增加 `studio_storage` 可写检查，关闭时不检查。备份包含数据库、uploads 及存在时的 studio 第三个包，两个媒体包都排除隐藏文件和 `.part`，默认共同保留 14 天；写歌音频目录（`FIONA_SONG_DIR`，默认 `backend/song_data/`，生产 `/var/lib/fiona/songs`）尚未纳入备份脚本（P2）。studio 打包失败会保留旧 studio 包、继续发布数据库和 uploads，并以退出码 1 报告部分失败。


WO2 追加 `GET /studio/projects/{pid}`、`GET /studio/projects/{pid}/assets` 和 `GET /studio/notices?after=<id>`，均隔离 owner、禁止缓存；素材列表不暴露文件路径。通知每页最多 50 条，同一任务只写一条，通知失败不会影响任务状态或费用结算，并在后续 tick 补写。删号会在原有工作室清理事务中一并删除通知。

WO3a「①拆解」可试读最多 20000 字素材，选择通读结论、风格提案、人物/场景/道具表。顶栏可切换作者自己的 Claude BYOK（使用配置里的模型）、千问或 DeepSeek；切换只影响之后的调用，不自动降级或重跑。确认原生报价对话框后才提交，美元与人民币分别显示，报价包含最多一次输出修正的上限。人物外形必须摘录原文；原文没写时标为「待作者补充」。试读在排队/运行时每 3 秒更新。

导演接口为 `GET /studio/brain/providers`、`PATCH /studio/projects/{pid}`、`POST /studio/projects/{pid}/brain/quote`、`POST /studio/projects/{pid}/brain/trial` 和 `GET /studio/projects/{pid}/brain/groups/{group_id}`。`providers=all` 采用严格策略：任一家不可用或任何预算检查失败，整体返回 409，不建任务、不发模型请求。报价不调用模型；正式提交在事务内重查累计额度。千问和 DeepSeek 计入工作室人民币日上限；Claude 按作者计入上海自然月美元上限，默认 $40。未知 Claude 型号必须设置 `FIONA_STUDIO_PRICE_<MODEL>`，格式见 `.env.example`。默认价格仍待核实，应以实际账单为准。

工作室看图由 Claude 直接处理，或交给 `FIONA_STUDIO_VISION_MODEL` 指定的千问视觉模型，默认 `qwen3-vl-plus`；DeepSeek 不接收图片。配置每次调用时读取，允许空值，空值使用默认模型且不告警；非空值须匹配 `^[a-z0-9][a-z0-9.\-]{1,63}$`，非法值回落默认并只告警一次。提供方接口的 `vision_via`、结果警告和手动评测报告会标出实际视觉模型。`qwen3-vl-plus` 暂按每百万 token 输入 ¥1、输出 ¥10 计价（待核实），可通过 `FIONA_STUDIO_PRICE_QWEN3_VL_PLUS={"input":1,"output":10,"cache_read":1}` 覆盖；旧 `qwen-vl-max` 价格保留供旧任务结算。自定义视觉模型须先配置单价，否则看图调用返回 409 且不发请求。此项仅配置工作室；聊天看图由 `FIONA_CHAT_VISION_MODEL` 单独配置（默认 `qwen3.8-omni-flash`）。

每次模型调用独立记账；SDK `max_retries=0`，超时、断连、5xx 和无法解析的响应保留额度为 uncertain，只有完整 4xx/429 释放。已收到的模型正文不符合 JSON/硬约束时，允许单独计费、单独预留的一次修正；第二次不合格终止为 invalid_output。同步导演任务没有上游任务号，只能核实未扣费后释放。原文及模型产物保存在作者任务记录中以支持后台执行，日志不记录原文、提示词或输出。

手动评测先运行 `cd backend && .venv/bin/python scripts/studio_brain_eval.py --text-file <素材> --providers claude qwen deepseek` 看报价；没有足额 `--yes-spend <人民币金额>` 时退出 2 且不请求。Claude 使用环境变量 `ANTHROPIC_API_KEY` 和 `--claude-model`，不经过数据库；可加 `--image <本地图片>`。报告在 `backend/studio_data/_eval/`。此命令只能由作者或主控手动执行。

「①拆解」把快照拆成场景单元再分成集。先设每集目标时长（默认 180–240 秒，可填 60–900）与可选的「大约几集」，点「报价」看整次拆解的花费，确认后开跑。小说来源先做结构化导入，圣经人物与每章细纲直接成为初始单元、梗概由罗盘拼成，这一步不花钱；随后按每批最多 10 章、24,000 字请导演模型以正文为准补全场景与人物外形。上传、粘贴和成稿先逐块通读，再汇总成梗概。进度按批显示，某一批失败、被拒或结果不确定时可以只重跑那一批，也能换一家模型重跑；不确定的批次要先核账释放才能重跑。费用计入全工作室当日额度与单次报价上限，Claude 走作者本月美元额度。

拆完得到故事梗概、人物/场景/道具总表和分集方案表，都能在页面里改：总表可增删改、合并同名条目、归档，原文没写外形的人物标「待作者补充」，工作室不会编造；分集方案可合并、拆分、挪动边界、改标题、改单集时长。批准分集方案即 G0 通过，批准后再改任何一处都会生成新版本并退回待批准。总表与分集方案可导出 Markdown。作品同步后页面会提示「拆解基于快照第 k 版」，可重新拆解。

WO3d「②定妆」把 G0 批准到可开拍的准备串起来：先确认开工设置（视频分辨率默认 480P、默认视频模型默认万相、语言中文/英文，画幅沿用项目设置），再由导演模型给出 2–3 个风格方案，作者选一个、可再微调文字并选定写实度（写实/动漫/3D），然后进入 G1 定妆。风格提案与出图都先报价、确认一次后才调用，提案输入只带摘要，不含原文全文；G0 未批准、未开工确认或未选风格时相关接口返回 409 且不发付费请求。

G1 定妆要求总表里的每个人物、场景、道具都定妆或标为「不需要定妆」。勾选条目、每项设 1–4 版后按批报价，确认一次即批量出图；定妆图固定 Seedream 5.0、2560×1440 横幅三视图、纯白背景。多个版本并排显示，选定一版并确认该条目，废版只归档不删除；可以上传参考图或以已选定版本派生新版本，也可以填写以后不得改动的「锁定特征」。原文没有外形描述的人物必须先补写外形才能出图；全部条目确认或跳过即 G1 通过。

声线只针对人物：每个角色最多配置 3 个试听方案（引擎、音色、语速、音高、表演指示、声线特效），用一句试听台词生成试听，作者选定一条定档。中文默认使用豆包语音 2.0，CosyVoice 与 edge-tts 保留为备选；英文使用免费 edge-tts。豆包方案可写最多 200 字的「表演指示」，用自然语言说明情绪、语气与场景；定档时再填写可修改的「角色基调」，后续逐句配音会把角色基调与每句表演指示合并使用。中文配音金额很小、不弹报价框但会先预留额度并受上限约束。声线特效提供机器人 / 巨兽 / 内心独白三档，特效后做两遍响度标准化，输出 48kHz 单声道 WAV，依赖系统安装的 ffmpeg。

出图与配音各有独立在途上限，可用 `FIONA_STUDIO_MAX_INFLIGHT_IMAGE`（默认 3）和 `FIONA_STUDIO_MAX_INFLIGHT_TTS`（默认 2）配置，合法 1–10，非法值回落默认并只告警一次。定妆图单价默认 `FIONA_STUDIO_PRICE_SEEDREAM_CNY=0.30` 元/张（待核实，以实际账单为准）；豆包语音默认 `FIONA_STUDIO_PRICE_DOUBAO_TTS_CNY_PER_10K_CHARS=3.0` 元/万字符，CosyVoice 默认 `FIONA_STUDIO_PRICE_COSYVOICE_CNY_PER_10K_CHARS=2.0` 元/万字符（均待核实，最低结算 0.01 元，表演指示不计费）。豆包 Key 取 `VOLC_SPEECH_API_KEY`，资源 ID 取 `VOLC_SPEECH_RESOURCE_ID`（默认 `seed-tts-2.0`）；在火山引擎「豆包语音」控制台开通「语音合成 2.0」，再到「API Key」页复制。配置均调用时读取。新增依赖 `edge-tts==7.3.1`，另需系统 `ffmpeg`；配置见 `backend/.env.example`。

WO3e「导演知识库」入口在 `/studio/kb`，只有工作室作者可访问。知识库是仓库里的本地 YAML：13 张语法卡、19 张场景卡（17 张内容卡和 2 张位置卡）、5 张模型能力卡、21 张反例卡，覆盖对话、打斗、追逐、悬疑揭示等 19 类场景。取材料时按场景类型、位置、节奏、情绪、人数、写实度、内外景和敏感标记选出模板、语法、模型卡与反例；注入文本总长不超过 8000 字，模板、位置与模型卡不会被裁掉。

页面有 7 个页签：语法、场景模板、模型能力、反例、案例库、节奏统计、试拆对比。卡片页签可按标签筛选和搜索，右侧显示完整字段；案例库可标好例/反例、改原因或归档；节奏统计累计不足 5 集时显示空态。试拆对同一场戏带知识库和不带知识库各拆 1 次，左右并排给出镜头表、模板 id、注入字数、知识库检查警告和审核结论；报价 15 分钟内只能确认 1 次，受单次与当日额度约束。

项目页头可选审核模型，默认千问 3.8 Max，也可选 Claude、DeepSeek 或关闭；关闭时不发审核请求、报价也不含审核费。审核失败只写进试拆结果，不影响试拆本身的状态。卡片、案例和统计都在本地，运行时不访问任何外部资源。本期只做知识库、页面与试拆，正式接进逐集拆镜留到 WO4。
